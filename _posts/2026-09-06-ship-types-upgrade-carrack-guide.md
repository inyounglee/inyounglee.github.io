# 항해 배 종류와 특징 · 증축 방법과 중범선까지

```
거래소에서 경범선 or 호위함 등록증 구매 (권장 시작점)
  → (선택) 개량형
  → 무역선 / 구축함
  → 중범선 점진·균형 / 용맹·비상
```

공식도 **바탈리부터 키우기보다 경범선·호위함 등록증을 거래소로 사는 쪽**을 권장합니다. 시간·재료 낭비가 훨씬 적습니다.

---

## 한눈에 보는 결론

| 목적 | 최종 배 | 이유 |
| --- | --- | --- |
| **교역(물물교환)** | **에페리아 중범선 — 점진** | 적재량·가방 칸이 가장 큼 |
| **교역 + 전투 한 대** | **중범선 — 균형** | 능력치 평균 · 입문 추천 |
| **해상 전투·괴수** | **중범선 — 용맹** | 함포 화력 특화 |
| **빠른 기동·이동** | **중범선 — 비상** | 속도·선회 특화 |

중간 목표만 잡으면:

| 목적 | 중간 배 |
| --- | --- |
| 교역 입문~중반 | **에페리아 무역선** (가방 30칸 · 10,000 LT) |
| 전투 입문~중반 | **에페리아 구축함** (함포 8문 · 기동·선실) |

---

## 1. 배 종류와 존재 이유

검은사막 배는 크게 **소형(이동)** / **대형(물물교환·증축)** / **특수(길드·지역)** 로 나뉩니다. **물물교환은 대형 선박만** 가능합니다.

### 1-1. 소형·입문 배 (교역 불가)

| 배 | 특징 | 존재 이유 |
| --- | --- | --- |
| **어선** | 근해 이동·낚시용 | 초보 연안 이동 |
| **에페리아 고속정** | 빠름 · 가방 적음 | 섬 지식·의뢰 동선 · 올비아 항해 강의 지원 |
| **기타 소형** | 이벤트·특수 선박 등 | 이동 편의 |

고속정은 **입문·이동용**이지, 중범선 루트의 본선이 아닙니다.

### 1-2. 대형 선박 — 증축 메인 루트

| 배 | 성향 | 특징 | 존재 이유 |
| --- | --- | --- | --- |
| **바탈리 범선** | 입문 | 벨리아 프라와 **1,000만** · 함포·수리 가능 · 물교 가능 | 대형 선박의 **출발점** (직접 키우면 비효율) |
| **에페리아 경범선** | 교역 쪽 | 적재·범용 균형 | → **무역선 → 점진/균형** |
| **에페리아 호위함** | 전투 쪽 | 화력·전투 성향 | → **구축함 → 용맹/비상** |
| **개량형 경범선/호위함** | 선택 | **일제사격·정밀포격** (조타 중 함포) | 해양 괴수·편의 · **다음 단계 필수 아님** |
| **에페리아 무역선** | 교역 | **가방 30칸 · 10,000 LT** · 일제사격 | 중반 교역의 핵심 |
| **에페리아 구축함** | 전투 | **함포 좌우 4+4** · 선실·기동 | 중반 해상전의 핵심 |
| **중범선 — 점진** | 교역 최종 | 적재 **최고** | 물물교환 끝판 |
| **중범선 — 균형** | 만능 | 전 능력 평균 | 배 한 대로 교역+전투 |
| **중범선 — 용맹** | 전투 최종 | **화력 최고** | 괴수·해상전 |
| **중범선 — 비상** | 기동 최종 | **속도 최고** | 빠른 루트·추격 |

```
[교역 루트]
경범선 ──► 무역선 ──► 중범선 점진 or 균형

[전투 루트]
호위함 ──► 구축함 ──► 중범선 용맹 or 비상
```

> **처음부터 고르세요.** 경범선 루트로는 용맹/비상, 호위함 루트로는 점진/균형을 만들 수 없습니다. (다른 루트 배를 새로 키워야 함)

### 1-3. 특수 선박

| 배 | 특징 | 존재 이유 |
| --- | --- | --- |
| **길드 갤리선** | 길드 공용 · 대형 전투 | 길드 대양·레이드 |
| **에페리아 거함** | 초대형 · 함포 다수 | 최상위 특수 운용 (일반 증축 루트와 별개) |
| **판옥선** | 아침의 나라 관련 대형 선박 | 지역·콘텐츠 특화 (일반 중범선 루트와 별개) |

일반 가문이 **교역·괴수·중범선**을 목표로 하면 **에페리아 대형 증축 루트**만 따라가면 됩니다.

> **2026년 9월 22일:** **대형 선박 탑승 중** 나루터지기 근처에서 **하선 없이** 선착장(수리·보급·화물 적재·상점 등)을 쓸 수 있고, 물물교환 UI에 **거리·근처 항구 길찾기**가 붙었습니다. 올비아 입문 동선은 [항해·교역 시작 가이드 3-5절](/blackdesert/2026/09/06/olvia-academy-sailing-trade-guide/)을 보세요.

## 2. 거래소 구매로 시작하기 (본 포스트 전제)

| 단계 | 할 일 |
| --- | --- |
| 1 | **통합 거래소** → 선박 등록증 **에페리아 경범선** 또는 **에페리아 호위함** 검색 |
| 2 | 목적에 맞게 구매 (교역=경범선 · 전투=호위함) |
| 3 | 등록증 **우클릭** → 선착장 나루터지기 → **선박 등록** |
| 4 | **찾기**로 소환 · 식량·포탄 **보급** |

| 선택 | 추천 |
| --- | --- |
| 물물교환·까마귀 주화 위주 | **경범선** |
| 해양 괴수·해상전 위주 | **호위함** |
| 아직 모르겠음 | **경범선 → 균형** 또는 완성 **중범선 균형**을 거래소로 (시세 여유 시) |

올비아 기간이면 [항해·교역 강의](/blackdesert/2026/09/06/olvia-academy-sailing-trade-guide/)로 **고속정·경범선**을 먼저 받아도 됩니다.

## 3. 증축은 어떻게 하나

1. 해당 배를 선착장에 **등록**  
2. 나루터지기 → **증축** 메뉴  
3. 재료를 **전부 투입** 후 증축  

**증축이 안 될 때**

- 장착 장비 **내구도**가 닳아 있음  
- 배에 **적재물·장착 장비**가 남아 있음  
- **선원**이 탑승 중  

개량(경범선/호위함 → 개량형)도 같은 나루터지기에서 진행합니다. **개량하지 않아도** 무역선·구축함으로 갈 수 있습니다. (괴수 사냥 편의를 위해 개량 권장)

## 4. 단계별 재료 · 예상 비용 · 기간

시세·매물·일일 효율에 따라 크게 달라집니다. 아래는 **거래소에서 경범선/호위함을 산 뒤** 직접 증축할 때의 감각용 대략치이며, **완성 중범선 거래소 구매**가 더 쌀 때도 많습니다.

### 4-1. (선택) 개량형 경범선 / 호위함

| 재료 (공통 요약) | 비고 |
| --- | --- |
| 에페리아 낡은 선수상·장갑·함포·돛 | 팔라시 구매 후 강화 |
| 규격 각목 250 · 강철 200 · 소나무 합판 500 · 아마포 100 · 단단한 기둥 30 | 거래소/제작 |
| 극 방어구 개량석 10 (경범선) / 극 무기 개량석 10 (호위함) | |

| 효과 | 조타 중 **일제사격·정밀포격** |
| --- | --- |
| 기간 | **수일** |
| 필수? | **아니오** (괴수·편의용) |

### 4-2. 경범선 → 무역선 / 호위함 → 구축함

**공통 조건 감각:** 장착 장비 **4종 +10** (파도의 블랙스톤 · 부위당 55개 · 합 **220개**, 강화 성공률 100%)

| 재료 | 무역선·구축함 공통/유사 | 수급 |
| --- | --- | --- |
| 선박 증축 허가증 | 무역선 / 구축함 | 팔라시 구매 → 파도스톤 강화 |
| +10 에페리아 낡은 장비 4종 | 선수상·장갑·함포·돛 | 팔라시 + 파도스톤 |
| **증축용 흑연 주괴 ×100** | 해양 괴수 진액 가열 등 | 괴수 · 라비니아 일지 · 거래소 |
| **증축용 목재 ×100** | 진액 장작패기 · 붉은 나무혹 등 | 동일 |
| **증축용 접착제 ×100** | 수액류 가열 | 동일 |
| **섬나무 증착합판 ×100** | 2단계 물물교환 | 물교 |
| **암염 주괴 ×100** (무역선) | 2단계 물물교환 | 물교 |
| **심해의 기억이 담긴 아교 ×4** | 3단계 물교 · 까주 · 일일 | |
| **심해초 줄기 ×4** | 까주 · 오킬루아 주간 등 | |
| 구축함 추가 | 파도빛 규격 각목 · 코발트 주괴 · 달의 비늘 합판 등 | 유령선·물교·까주·일일 |

**라비니아의 선박 증축 일지 I~VII**는 **7일**에 걸쳐 순서대로 열려, 무역선/구축함 재료를 크게 덜어 줍니다. (까마귀의 둥지)

| 예상 | 무역선 / 구축함 |
| --- | --- |
| 기간 | 물교·괴수·일일 병행 시 대략 **2~6주** (집중도·시세에 따라) |
| 은화 | 허가증·장비·재료 시세 합 **수십억**대까지 갈 수 있음 |
| 까마귀 주화 | 재료를 까주로 때우면 **수천~1만+** |

### 4-3. 무역선/구축함 → 중범선

| 출발 | 결과 |
| --- | --- |
| 무역선 | **점진** 또는 **균형** |
| 구축함 | **용맹** 또는 **비상** |

**공통 골격 (종류별 수량은 다름)**

| 재료 | 수급 |
| --- | --- |
| +10 무역선/구축함 장비 4종 (흑룡 선수상·개량형 장갑·메이나 함포·비층 돛) | 선박 부품 공방 · 파도스톤 |
| **달의 핏줄이 새겨진 아마포** (약 180~210) | 칸 힘줄 말리기 · 까주 · 일일 |
| **짙은 파도빛이 감도는 규격 각목** (약 144~170) | 해적선 파편 · 까주 · 일일 |
| **화려한 암염 주괴 ×30** | 5단계 물교 · 까주 (400/개 등) |
| **화려한 진주 결정 ×30** | 5단계 물교 · 까주 |
| **심해의 눈물** (약 42~50) | 5단계 물교 · 마고리아의 별 · 주간/일일 · 낚시 등 |

종류마다 아마포·각목·눈물 수량이 조금씩 다릅니다. 정확한 칸 수는 게임 내 증축 UI·[공식 가이드](https://www.kr.playblackdesert.com/ko-KR/Wiki?wikiNo=295)를 확인하세요.

| 예상 | 중범선 1척 (직접 증축) |
| --- | --- |
| 기간 | 일일·주간·물교·칸 병행 시 대략 **1~3개월+** (퀘만 의존하면 더 김) |
| 은화 | 시세·자가수급 비율에 따라 **수십억~백억** 감각 (재료 올바이 시) |
| 까마귀 주화 | 재료를 까주로 메우면 **수만** 단위도 가능 |
| 대안 | **거래소에서 완성 중범선** 구매가 시간 대비 이득인 경우가 많음 |

커뮤니티 기준 예: 구축함→용맹을 재료 시세로만 환산하면 **은화 수십억 + 까주 수만**이 나오기도 하고, 퀘스트 재료만 돌리면 **추가 100일** 가까이 잡는 계산도 있습니다. **반드시 현재 시세로 다시 계산**하세요.

## 5. 교역 최종 vs 전투 최종 — 고르는 법

```
물물교환이 주력인가?
  YES → 경범선 → 무역선 → 점진 (또는 균형)
  NO  → 해상 전투/괴수가 주력인가?
           YES → 호위함 → 구축함 → 용맹 (또는 비상)
           둘 다 → 균형 1대  or  점진+용맹 2대
```

| 질문 | 추천 |
| --- | --- |
| 까마귀 주화·5~7단 물교가 목표 | **점진** |
| 배 예산·관리 1대만 | **균형** |
| 벨·칸·해적선·해상 PvP | **용맹** |
| 루트 순환·추격·이동 쾌적 | **비상** |

중범선 이후에는 **녹템 → 파템** 선박 장비(함포·선수상·돛·장갑)와 **부품 개조**로 성능을 더 올립니다. 교역이든 전투든 **파템**이 실질 최종 스펙입니다.

## 6. 실전 체크리스트

```
□ 목적 정하기: 교역(점진/균형) vs 전투(용맹/비상)
□ 거래소에서 경범선 or 호위함 등록증 구매 · 등록
□ (선택) 개량형 — 일제사격 해금
□ 장비 4종 +10 (파도스톤) · 적재/선원 비운 뒤 증축
□ 무역선 or 구축함 재료: 물교 · 괴수 · 라비니아 일지 7일
□ 중범선 재료: 5단 물교 · 일일/주간 · 칸 · 까주 상점
```
