# 엠마 바탈리의 기록일지 진행 가이드

## 일지 여는 법

1. 메뉴(ESC) → **모험(F5)** → **모험일지 책장**
2. **「올비아 아카데미 성장일지」** → **엠마 바탈리의 기록일지**
3. 장 완료 후 일지 화면에서 **보상 문구를 클릭**해야 아이템이 지급됩니다. (자동 수령 아님)

| 항목 | 내용 |
| --- | --- |
| 횟수 | **가문당 1회** |
| 순서 | **1~12장은 조건만 맞으면 병렬 가능** · **13장은 1~12 전부 완료 후** 흑정령 대화 |
| 권장 레벨 | 일부 의뢰·토벌은 **58+** 권장 |

## 한눈에 보는 장별 보상

| 장 | 완료 조건 | 보상 |
| ---: | --- | --- |
| **1** | 이고르 바탈리의 모험일지 **5권** 완료 | 발크스의 조언(+180) **2** |
| **2** | `[까마귀의 둥지] 까마귀의 용병` 의뢰 완료 | 고대의 망치 - 동(V) **5** |
| **3** | `[승급] 광 : 불멸의 까마귀 휘장` 의뢰 완료 | 고대의 블랙스톤 - 동(V) **1** |
| **4** | `툰그라드 대사원` · `파푸에게 주는 선물` 완료 | 새벽의 정수 **50** |
| **5** | `[아침의 나라] 도깨비의 선물` · `[아침의 나라] 태백을 호령하는 자` 완료 | 고대의 망치 - 동(V) **5** |
| **6** | `[엘비아] 크자카 : 잠식의 결계 V` 완료 | 고대의 블랙스톤 - 동(V) **1** |
| **7** | 검은 사당 — 동해도(개인) **산군 구재시니** 토벌 | 발크스의 조언(+210) **2** |
| **8** | 검은 사당 — 동해도(개인) **구미호 구재시니** 토벌 | 고대의 망치 - 운(VI) **5** |
| **9** | 어둠의 틈 — **비겁한 베그** 처치 | 고대의 블랙스톤 - 운(VI) **1** |
| **10** | 어둠의 틈 — **우둔한 나무 정령** 처치 | 새벽의 정수 **50** |
| **11** | 어둠의 틈 — **페리드** 처치 | 고대의 망치 - 운(VI) **5** |
| **12** | 어둠의 틈 — **아히브의 그리폰** 처치 | 고대의 블랙스톤 - 운(VI) **1** |
| **13** | 1~12장 전부 완료 후 **흑정령**과 대화 | 고대의 블랙스톤 - 우(VII) **2** |

### 카라자드 강화 지원으로 보면

| 카라자드 단계 | 확정 강화석(고대의 블랙스톤) | 하락 방지(고대의 망치) |
| --- | --- | --- |
| 동(V) → 운(VI) | 동 블랙스톤 **2** (3·6장) | 동 망치 **10** (2·5장) |
| 운(VI) → 우(VII) | 운 블랙스톤 **2** (9·12장) | 운 망치 **10** (8·11장) |
| 우(VII) → 풍(VIII) | 우 블랙스톤 **2** (13장) | — |

남는 망치·블랙스톤은 **가열 → 크론석**으로 바꿀 수 있습니다. (아이템 소멸)

## 권장 진행 순서

```
1장(이고르 5권)
  → 2장(까마귀의 용병) → 3장(광 휘장 승급)
  → 4장(툰그라드·파푸) · 5장(아침의 나라) · 6장(잠식의 결계 V) 병렬
  → 7·8장(동해도 산군·구미호 구재시니)
  → 9~12장(어둠의 틈 4종)
  → 13장(흑정령)
```

동→운 재료만 급하면 **2·3·5·6장**을 먼저 챙기면 됩니다.

---

## 장별 진행 요약

### 1장 — 이고르 바탈리 5권

- 모험일지 책장 → **이고르 바탈리의 모험일지** 1~5권 완료
- 5권까지 가면 가문 **공방합** 보너스도 같이 열리므로 하이퍼 부스트 **750** 루트와도 겹칩니다. ([하이퍼 부스트 6단계](https://www.inyounglee.kr/blackdesert/2026/08/15/hyper-boost-equipment-guide/#step-6))

### 2장 — `[까마귀의 둥지] 까마귀의 용병`

- 대양 **까마귀의 둥지** 연속 의뢰의 마지막 구간
- 시작 의뢰: **`[까마귀의 둥지] 까마귀의 둥지로`**
- 흑정령(`/` 키)을 불러와 **의뢰(A) → 추천 의뢰**에서 수주하여 시작하면 됩니다. (레벨 **56+**)
- 상세 의뢰 목록·NPC: **[까마귀의 둥지 연속 의뢰](https://blueforget.tistory.com/263)** · [도도리 요약](https://dodoripyogirok.tistory.com/entry/%EC%9D%98%EB%A2%B0-%EC%95%88%EA%B0%9C%EA%B0%80-%EC%9E%90%EC%9A%B1%ED%95%9C-%EB%AF%B8%EC%A7%80%EC%9D%98-%EC%84%AC-%EA%B9%8C%EB%A7%88%EA%B7%80%EC%9D%98-%EB%91%A5%EC%A7%80)
- 먼 바다 이동용 배가 없으면 → **[올비아 항해·교역 강의](https://www.inyounglee.kr/blackdesert/2026/09/06/olvia-academy-sailing-trade-guide/)** 로 고속정·경범선 수령 (또는 거래소 구매)

완료 시 **장 : 불멸의 까마귀 휘장**도 받게 되어, 3장(광 승급) 선행이 됩니다.

### 3장 — `[승급] 광 : 불멸의 까마귀 휘장`

1. **장** 휘장 장착 → 불멸의 나락에서 일일·주간으로 **까마귀의 검은 보옥** 수집  
2. 쵸르피에게 보옥 **10개** → `[승급] 광 : 봉인된 까마귀의 승급서`  
3. 가방의 **광 : 까마귀의 승급서**로 승급전 (발킨 → 철벽의 사나이 → 에버가트 → 반 라이커)  
4. 실패 시 의뢰 포기 후 재수주 · 재도전은 보옥 **5개**

입장·휘장·보옥·승급 요약: **[불멸의 나락 입장 방법 및 콘텐츠](https://dodoripyogirok.tistory.com/entry/%EB%B6%88%EB%A9%B8%EC%9D%98-%EB%82%98%EB%9D%BD-%EC%9E%85%EC%9E%A5-%EB%B0%A9%EB%B2%95-%EB%B0%8F-%EC%BB%A8%ED%85%90%EC%B8%A0)**  
의뢰 DB: [BDO Codex — 광 : 불멸의 까마귀 휘장](https://bdocodex.com/kr/quest/3723/12/)

### 4장 — 툰그라드 대사원 · 파푸에게 주는 선물

가문 **공격력 +1 / 방어력 +1** 의뢰이자 일지 4장 조건입니다. ([공식 — 능력치 올리기](https://www.kr.playblackdesert.com/ko-KR/Wiki?wikiNo=308))

| 의뢰 | 수주 | 건넬 재료 (강화되지 않은 것 중 3개) | 효과 |
| --- | --- | --- | --- |
| **툰그라드 대사원** | 오딜리타 — 어머니의 신탁 → 생각이 잠든 묘 **푸른 사마귀** | 툰그라드 목걸이·귀걸이·허리띠·반지 | 가문 공격력 **+1** |
| **파푸에게 주는 선물** | 그라나 **메린돌라** (카마실비아의 빛 지식) | 숲 로나로스의 반지·시칠/세랍 목걸이·카드리 수호자 반지 | 가문 방어력 **+1** |

추천 의뢰 `[모험 지원] 메린돌라의 축복…` / `비오렌치아의 축복…`에서도 안내됩니다.

### 5장 — 아침의 나라

- `[아침의 나라] 도깨비의 선물` · `[아침의 나라] 태백을 호령하는 자` 완료
- 아침의 나라 메인·설화(태백 호령) 루트를 끝까지 진행하면 충족됩니다.
- 하이퍼 부스트 **태고 방어구** 선행과도 겹칩니다.

### 6장 — 잠식의 결계 V

- 엘비아 서버 · `[엘비아] 흑요석의 재` 등 선행 후 **크자카 : 잠식의 결계 I~V**
- **V**까지 클리어해야 일지 6장 + 가문 **공격력 +1** 등 보너스

### 7~8장 — 검은 사당 동해도(개인)

| 장 | 토벌 |
| ---: | --- |
| 7 | **산군** 구재시니 |
| 8 | **구미호** 구재시니 |

메뉴 → 모험 → **검은 사당** → 동해도(개인) → 해당 보스 · 난이도 **구재시니**.

### 9~12장 — 어둠의 틈

**2026년 8월 5일** 업데이트로 황해도(파티) 도전 목표가 **어둠의 틈**으로 바뀌었습니다. 보상은 동일합니다. ([공식 공지](https://www.kr.playblackdesert.com/ko-KR/News/Detail?groupContentNo=15998&countryType=ko-KR))

| 장 | 일지명 | 처치 목표 |
| ---: | --- | --- |
| 9 | 7월 8일의 일지 | **비겁한 베그** |
| 10 | 7월 23일의 일지 | **우둔한 나무 정령** |
| 11 | 8월 18일의 일지 | **페리드** |
| 12 | 9월 8일의 일지 | **아히브의 그리폰** |

메뉴 → 모험 → **어둠의 틈**에서 해당 보스를 처치하면 됩니다. (솔로·파티 가능, 황해도 도전보다 진입 난이도가 낮음)

### 13장 — 흑정령

1~12장 보상까지 수령한 뒤 흑정령과 대화 → **고대의 블랙스톤 - 우(VII) 2개**.

## 체크리스트

```
□ 1장  이고르 5권
□ 2장  까마귀의 용병 (+ 장 휘장)
□ 3장  광 휘장 승급 (보옥 10)
□ 4장  툰그라드 대사원 + 파푸에게 주는 선물
□ 5장  도깨비의 선물 + 태백을 호령하는 자
□ 6장  잠식의 결계 V
□ 7장  산군 구재시니
□ 8장  구미호 구재시니
□ 9장  어둠의 틈 — 비겁한 베그
□ 10장 어둠의 틈 — 우둔한 나무 정령
□ 11장 어둠의 틈 — 페리드
□ 12장 어둠의 틈 — 아히브의 그리폰
□ 13장 흑정령 대화
□ 일지에서 장별 보상 클릭 수령
```
