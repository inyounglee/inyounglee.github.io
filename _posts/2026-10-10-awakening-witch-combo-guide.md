아래 내용은 **2026년 10월 기준 한국 검은사막 PC판**입니다. 각성 무기는 **아드혼**입니다. 공식 콤보 강의는 [전승 위치 PvP](https://www.kr.playblackdesert.com/ko-KR/News/Detail?countryType=ko-KR&groupContentNo=9879)라서, 각성 사냥 키는 2025년 4월 밸런스 이후 공식 포럼 공략과 2026년 인벤 위치 게시판에서 많이 참고된 두 글을 따릅니다.

사냥은 아래 여섯 기술을 이어서 씁니다.

| 기술 | 입력 |
| --- | --- |
| **전류 파동** | `Shift + F` |
| **감벼락** | `S + 우클릭` |
| **뇌전 폭풍** | `S + F` |
| **균열의 파도** | `S + 좌클릭 + 우클릭` |
| **균형 붕괴** | `Shift + 좌클릭` |
| **시련의 질곡** 또는 **번개의 세례** | `Shift + 우클릭` 또는 `W + 우클릭` |

여섯 기술이 모두 재사용 중이면 **거부하는 가시** `Shift + Q`를 넣습니다.

## 키 {#keys}

각성 상태에서 누르는 키입니다. 기술 창은 `K`, 각성 탭에서 확인합니다. 아래 입력은 2026년 4월·9월 인벤 글과 2025년 4월 공식 포럼 글이 같습니다.

| 기술 | 입력 | 콤보에서 |
| --- | --- | --- |
| **전류 파동** | `Shift + F` | 사이클의 시작. 치명타 확률이 낮아서 특화를 여기에 붙입니다 |
| **감벼락** | `S + 우클릭` | 두 번째. 기술 자체에 치명타 확률 버프가 있습니다 |
| **뇌전 폭풍** | `S + F` | 범위가 넓은 딜. 특화는 버프를 붙입니다 |
| **번개의 세례** | `W + 우클릭` | 감벼락, 뇌전 폭풍 다음에 이어 쓰기 좋습니다 |
| **균열의 파도** | `S + 좌클릭 + 우클릭` | 사냥 딜의 중심. 마력 회피 직후에 쓰면 선딜이 줄고 백어택이 됩니다 |
| **균형 붕괴** | `Shift + 좌클릭` | 사이클을 마무리하는 딜 |
| **시련의 질곡** | `Shift + 우클릭` | 두 번째 사이클, 또는 입문 루프의 마지막 |
| **거부하는 가시** | `Shift + Q` | 전류 파동 직후, 또는 전부 재사용 중일 때. 공격력 감소가 있습니다 |
| **범람하는 맹독** | `W + E` | 사이클 사이. 걸어가며 깔아 마법 방어력을 깎습니다 |
| **마력 회피** | `Shift + 방향키` | 균열의 파도 앞. 몬스터를 통과한 뒤 뒤에서 때립니다 |
| **마력의 방패** | `Q` | 쿨이 돌 때마다. 받는 피해를 줄입니다 |
| **아드혼의 정신** | `Shift + E` | 재사용 3분 버프. 치유의 등대와 키가 겹칠 수 있습니다 |

`Shift + E`는 [나무위키 위치 스킬](https://namu.wiki/w/%EC%9C%84%EC%B9%98(%EA%B2%80%EC%9D%80%EC%82%AC%EB%A7%89)/%EC%8A%A4%ED%82%AC)에 적힌 아드혼의 정신 키입니다. 인게임 기술 창의 키를 따르면 됩니다.

## 사냥 콤보 {#combo}

두 글 모두 같은 기술을 씁니다. 차이는 마지막에 어떤 기술을 두는지, 그리고 **거부하는 가시**를 사이클 안에 넣는지입니다. 순서가 꼬이면 특화가 중간에 끊기니, 아래 표 순서대로 연습하면 됩니다.

### 2026년 9월 — 두 사이클로 도는 사냥 {#cycle-sep}

출처는 [파페피포푸, 인벤 위치 게시판, 2026-09-01](https://www.inven.co.kr/board/black/4346/34784)이고, 추천이 5개 달렸습니다. 글쓴이는 해외 가이드 작성자 루니스톰 이후로 각성 위치 콤보가 이 형태로 모였다고 적었습니다. 그 글에는 루니스톰 원문 주소가 없습니다.

사이클을 시작하기 전에 아래를 한 번 깔아 둡니다.

| 순서 | 기술 | 입력 |
| --- | --- | --- |
| 0 | **범람하는 맹독** | `W + E` |
| 0 | **신속의 주문** 뒤 **마력의 방패**, 이어서 Q 가드 | 신속 → `Q` → `Q` |
| 0 | 신속 자리에 **아드혼의 정신**(3분) 또는 흑정령 분노 100% 흡수 | 셋 중 쿨이 돌아온 것 |

1사이클입니다. 번개의 세례까지 한 번에 이어 갑니다.

| 순서 | 기술 | 입력 |
| --- | --- | --- |
| 1 | **전류 파동** | `Shift + F` |
| 2 | **감벼락** | `S + 우클릭` |
| 3 | **뇌전 폭풍** | `S + F` |
| 4 | **번개의 세례** | `W + 우클릭` |
| 5 | **균열의 파도** | `S + 좌클릭 + 우클릭` |
| 6 | **균형 붕괴** | `Shift + 좌클릭` |

2사이클입니다. 전류 파동 다음에 가시를 넣고, 번개의 세례 자리에는 시련의 질곡을 넣습니다.

| 순서 | 기술 | 입력 |
| --- | --- | --- |
| 1 | **전류 파동** | `Shift + F` |
| 2 | **거부하는 가시** | `Shift + Q` |
| 3 | **감벼락** | `S + 우클릭` |
| 4 | **뇌전 폭풍** | `S + F` |
| 5 | **시련의 질곡** | `Shift + 우클릭` |
| 6 | **균열의 파도** | `S + 좌클릭 + 우클릭` |
| 7 | **균형 붕괴** | `Shift + 좌클릭` |

1사이클 다음에는 2사이클, 그다음은 다시 1사이클입니다. **균열의 파도** 직전에는 **마력 회피** `Shift + S`(몬스터 무리를 통과하는 방향)를 넣습니다. 선딜이 짧아지고, 기술이 끝나는 자리가 몬스터의 뒤가 됩니다. 각성 위치는 이동기가 짧아서, 이렇게 자리를 잡으면 딜이 덜 새어 나갑니다.

글에 적힌 이유는 아래와 같습니다.

- **감벼락 → 뇌전 폭풍 → 번개의 세례**는 키를 누르는 흐름이 자연스럽습니다.
- **거부하는 가시**는 전류 파동 뒤에서 선딜이 짧아집니다. 기술 자체의 공격력 감소에, 특화의 방어력 감소와 피해 감소가 함께 들어갑니다.
- **범람하는 맹독**은 다음 젠으로 걸어가며 `W`를 누른 채 `E`로 미리 깔아 둡니다.
- **신속의 주문**은 계속 유지되지는 않습니다. 3분 버프, 흑정령 100% 흡수와 나눠 쓰면 시전 속도가 덜 끊깁니다. 각성에서 신속을 쓰면 잠깐 지팡이로 바뀌었다가 아드혼으로 돌아옵니다. 그 사이에 `Q`를 누르면 **마력의 방패**가 나가고, 이어서 Q 가드까지 쓰면 피해 감소가 더 쌓입니다.

### 2026년 4월 — 같은 줄기를 두 번 도는 입문 {#cycle-apr}

출처는 [베리, 인벤 위치 게시판, 2026-04-10 수정](https://www.inven.co.kr/board/black/4346/34723)입니다. 가시는 사이클 밖에 두고, 마지막 기술만 바꿉니다. 순서가 짧아서 외우기 쉽습니다.

시작은 독 장판입니다. 그 글은 `E`로 적었고, 9월 글의 **범람하는 맹독** `W + E`와 같은 자리입니다.

첫 바퀴입니다.

| 순서 | 기술 | 입력 |
| --- | --- | --- |
| 1 | **전류 파동** | `Shift + F` |
| 2 | **감벼락** | `S + 우클릭` |
| 3 | **뇌전 폭풍** | `S + F` |
| 4 | **균열의 파도** | `S + 좌클릭 + 우클릭` |
| 5 | **균형 붕괴** | `Shift + 좌클릭` |
| 6 | **시련의 질곡** | `Shift + 우클릭` |

둘째 바퀴는 마지막만 **번개의 세례** `W + 우클릭`으로 바꿉니다.

| 순서 | 기술 | 입력 |
| --- | --- | --- |
| 1 | **전류 파동** | `Shift + F` |
| 2 | **감벼락** | `S + 우클릭` |
| 3 | **뇌전 폭풍** | `S + F` |
| 4 | **균열의 파도** | `S + 좌클릭 + 우클릭` |
| 5 | **균형 붕괴** | `Shift + 좌클릭` |
| 6 | **번개의 세례** | `W + 우클릭` |

여섯 기술이 모두 재사용 중이면 **거부하는 가시** `Shift + Q`를 씁니다. **마력의 방패** `Q`는 쿨이 돌아올 때마다 켭니다. **신속의 주문**은 회피를 많이 할 때, 멀리 이동할 때, 파티로 사냥할 때 씁니다. 효과는 30초이고, 전류 파동의 시전 속도 증가와는 겹치지 않습니다. 3분 버프와 흑정령 100% 흡수는 번갈아 쓰면 됩니다.

### 2025년 4월 2일 밸런스 직후 {#cycle-2025}

출처는 [공식 포럼 — 2025.4.2 각성위치 밸패후 콤보·특화](https://www.kr.playblackdesert.com/ko-KR/Forum/ForumTopic/Detail?_opinionNo=132012&_topicNo=132029)입니다. 샤이 버프가 없을 때의 기본 순서는 **감벼락**으로 시작합니다.

| 순서 | 기술 | 입력 |
| --- | --- | --- |
| 1 | **감벼락** | `S + 우클릭` |
| 2 | **전류 파동** | `Shift + F` |
| 3 | **뇌전 폭풍** | `S + F` |
| 4 | **균열의 파도** | `S + 좌클릭 + 우클릭` |
| 5 | **균형 붕괴** | `Shift + 좌클릭` |
| 6 | **시련의 질곡** | `Shift + 우클릭` |

같은 글에서 샤이 버프가 있을 때는 여기에 **거부하는 가시** `Shift + Q`, **폭류**, **번개의 세례** `W + 우클릭`을 더합니다. 그 글에서 확인한 부분에는 폭류의 키가 없어서, 키는 기술 창에서 보면 됩니다. 2026년 두 글은 시작을 **전류 파동** `Shift + F`로 바꾸어 두었습니다.

## 콤보 사이에 넣는 키 {#between}

딜 사이클 사이에, 상황에 맞춰 넣는 키입니다.

| 상황 | 기술 | 입력 |
| --- | --- | --- |
| 팩 뒤로 붙일 때 | **마력 회피** 후 **균열의 파도** | `Shift + S` → `S + 좌클릭 + 우클릭` |
| 다음 젠으로 걷는 중 | **범람하는 맹독** | `W + E` |
| 피해를 줄일 때 | **마력의 방패** | `Q` |
| 시전 속도가 끊겼을 때 | **신속의 주문**, **아드혼의 정신**, 흑정령 100% 흡수 | 쿨이 돌아온 것 하나 |
| 기술이 모두 재사용 중일 때 | **거부하는 가시** | `Shift + Q` |

흑정령 분노 흡수는 많은 클래스가 기본 키 `Z`를 씁니다. 위치도 단축키를 바꾸지 않았다면 `Z`입니다. 흡수 키를 바꾸면, 거기에 묶인 심화 키도 함께 바뀝니다.

## 기술 심화 {#rabam}

기술 심화는 기술 창 `K` 위의 **기술 심화** 탭에 있습니다. 56레벨 이후에 열리고, 56·57·58에서 **둘 중 하나만** 배웁니다. 기술 포인트는 소모되지 않고, 선행 기술만 있으면 됩니다. 다른 쪽으로 바꾸려면 기술 교본이 필요합니다.

기술 이름은 [인벤 기술 DB — 위치](https://black.inven.co.kr/dataninfo/skill/?reqjob=32)를, 키와 사냥용 선택은 [BDFoundry Witch Class Guide, 2023-04-14](https://www.blackdesertfoundry.com/witch-class-guide/)를 따릅니다. 2026년 9월 콤보도 심화를 딜 사이클에 넣지 않습니다. 쿨이 빈 사이에, 파티 회복·마나·보호용으로 슬롯에서 씁니다.

| 레벨 | 입력 | 사냥에 찍는 쪽 | 다른 쪽 | 선행 |
| --- | --- | --- | --- | --- |
| **56** | `Shift + X` | **현자의 등대** | 현자의 낙뢰 | 현자의 기억 + 치유의 등대 IV / 벼락 V |
| **57** | `Shift + Z` | **신속한 지진** | 번개의 진동 | 지진 IV + 신속의 주문 III / 번개 사슬 IV |
| **58** | 슬롯만 | **마나 화살** | 번개 화살 | 다중 마법 화살 + 마나 흡수 III / 번개 폭풍 III |

- **현자의 등대**는 치유의 등대를 주문 없이 쓰는 회복입니다. 56레벨 심화는 회복 쪽을 고르는 경우가 많습니다. ([Inven Global, 위치 56 심화](https://www.invenglobal.com/blackdesertonline/articles/4542/level-56-rabam-skill-recommendations-which-one-should-you-choose-between-the-two))
- **현자의 낙뢰**는 경직이 있는 낙뢰입니다. 전승에서 잔류 번개와 이을 때 고릅니다.
- **신속한 지진**은 슈퍼 아머와 흡입이 있어서, 사냥 중 빈 쿨을 메울 때 먼저 고릅니다. **번개의 진동**은 피해와 다운 스매시가 있고, 사용하는 동안 보호 판정이 없습니다.
- **마나 화살**은 전방 가드와 마나 흡수가 있습니다. **번개 화살**은 직선으로 나가는 딜이고, 전승에서 잔류 번개로 이어 쓸 때 고릅니다.

각성으로 사냥한다면 표의 사냥 칸인 **현자의 등대**, **신속한 지진**, **마나 화살**을 고르면 됩니다.

## 기술 특화 {#addon}

특화는 50, 52, 54, 56, 58, 60레벨마다 하나씩, **기술 6개**에 효과를 **2개씩** 붙입니다. 대도시 기술 교관에게 받으면 됩니다. 이어진 기술은 첫 단계만 특화해도 마지막 단계까지 효과가 들어가고, 소환수가 때리면 특화는 발동하지 않습니다. 기준은 [공식 기술 특화](https://www.kr.playblackdesert.com/ko-KR/Wiki?wikiNo=67)입니다.

지속 시간은 그 기술의 재사용 대기시간으로 단계가 갈립니다.

| 단계 | 재사용 대기시간 | 능력치 향상 | 피해 증가 | 방어 향상 | 능력치 감소 |
| --- | --- | --- | --- | --- | --- |
| 1 | 5초 이하 | 7초 | 5초 | 10초 | 7초 |
| 2 | 5초 초과 13초 미만. 13초 이상이어도 쿨 중에 쓸 수 있으면 2단계 | 12초 | 7초 | 15초 | 10초 |
| 3 | 13초 이상 | 20초 | 10초 | 25초 | 12초 |

아래 여섯 기술은 인벤 기술 DB와 2025년 포럼에서 **2단계**로 나옵니다. 그래서 치명타 확률·공격/시전 속도·이동 속도는 12초, 백어택·치명타 피해는 7초, 방어력 감소는 10초, 피해 감소 버프는 15초로 적습니다. 패치로 쿨이 바뀌면 기술 창에 적힌 시간을 따르면 됩니다.

생명력 회복 특화의 현재 문구는 타격한 개체마다 **생명력 35**입니다. 위치만의 숫자가 아니라, 특화 목록에 공통으로 적힌 수치입니다. ([인벤 기술 DB의 2단계 특화 목록](https://black.inven.co.kr/dataninfo/skill/?code=2541&reqjob=20), [2025년 GM노트 금수랑 특화 표기](https://www.kr.playblackdesert.com/ko-kr/News/Detail?countryType=ko-kr&groupContentNo=15755))

### 2026년 9월 사냥 세팅 {#addon-2026}

[파페피포푸, 2026-09-01](https://www.inven.co.kr/board/black/4346/34784)의 표입니다. 전류 파동으로 시작하는 9월 콤보에 맞춘 구성입니다.

| 기술 | 입력 | 효과 1 | 효과 2 | 글에 적힌 이유 |
| --- | --- | --- | --- | --- |
| **전류 파동** | `Shift + F` | 치명타 확률 +30% (12초) | 모든 방어력 −20 (10초) | 시작 기술이고 치명타 확률이 낮습니다. 방어력 감소도 잘 들어갑니다 |
| **감벼락** | `S + 우클릭` | 공격/시전 속도 +10% (12초) | 이동 속도 +10% (12초) | 치명타 확률은 기술 자체 버프가 담당합니다 |
| **뇌전 폭풍** | `S + F` | 백어택 피해 +5% (7초) | 치명타 피해 +5% (7초) | 맞는 범위가 고르지 않아 버프를 붙입니다 |
| **균열의 파도** | `S + 좌클릭 + 우클릭` | 모든 방어력 −20 (10초) | 타격당 생명력 35 | 사냥 딜의 중심입니다. 마력 회피 뒤에 써서 피흡이 잘 들어옵니다 |
| **균형 붕괴** | `Shift + 좌클릭` | 백어택 피해 +5% (7초) | 치명타 피해 +5% (7초) | 백어택과 치명타 피해를 한 번 더 유지합니다 |
| **거부하는 가시** | `Shift + Q` | 모든 방어력 −20 (10초) | 모든 피해 감소 +20 (15초) | 자체 공격력 감소와 겹칩니다. 마력의 방패, Q 가드와 피해 감소가 이어집니다 |

이 여섯 기술을 위 2사이클 순서대로 누르면, 치명타 확률·시전 속도·백어택·치명타 피해·방어력 감소가 사이클 안에서 다시 갱신됩니다.

### 2025년 4월 포럼 세팅 {#addon-2025}

출처는 [공식 포럼, 2025-04-02](https://www.kr.playblackdesert.com/ko-KR/Forum/ForumTopic/Detail?_opinionNo=132012&_topicNo=132029)입니다. 감벼락에 치명타 확률 버프가 추가된 직후의 구성입니다. 치명타 확률은 **감벼락**에, 몬스터 공격력은 **전류 파동**에 붙입니다. 2026년 9월 글은 치명타 확률을 전류 파동으로 옮겨 두었습니다.

| 기술 | 입력 | 효과 1 | 효과 2 |
| --- | --- | --- | --- |
| **감벼락** | `S + 우클릭` | 치명타 확률 +30% (12초) | 공격/시전 속도 +10% (12초) |
| **전류 파동** | `Shift + F` | 몬스터 공격력 +30 (12초) | 모든 방어력 −20 (10초) |
| **뇌전 폭풍** | `S + F` | 백어택 피해 +5% (7초) | 치명타 피해 +5% (7초) |
| **균열의 파도** | `S + 좌클릭 + 우클릭` | 모든 방어력 +20 (15초) | 이동 속도 +10% (12초) |
| **균형 붕괴** | `Shift + 좌클릭` | 모든 방어력 −20 (10초) | 인간족 추가 피해 −15 (10초) |
| **거부하는 가시** 또는 **시련의 질곡** | `Shift + Q` 또는 `Shift + 우클릭` | 백어택 피해 +5% (7초) | 치명타 피해 +5% (7초) |

사냥이라면 9월 표부터 맞추면 됩니다. 인간족에게 들어가는 피해를 줄여야 하는 전투가 잦다면, 균형 붕괴의 효과만 2025년 표로 바꿉니다. 한 기술에 붙일 수 있는 효과는 두 개입니다.

## 흐름과 본 기술 {#flow}

흐름은 따로 누르는 키가 없습니다. 배우면 본래 기술을 쓸 때 파수꾼의 공격이 함께 나갑니다. 위 콤보에 쓰는 흐름은 아래와 같습니다.

| 흐름 | 같이 나가는 기술 |
| --- | --- |
| **흐름: 테트의 전류** | 전류 파동 |
| **흐름: 테트의 분노** | 뇌전 폭풍 |
| **흐름: 완벽한 신호** | 균열의 파도 |
| **흐름: 고르 띄우기** | 균형 붕괴 |
| **흐름: 고르 굴리기** | 시련의 질곡 |

본 기술은 **균형 붕괴, 균열의 파도, 폭류, 뇌전 폭풍** 가운데 하나만 배울 수 있습니다. 하나를 배우면 나머지 셋은 잠깁니다. ([인벤 기술 DB](https://black.inven.co.kr/dataninfo/skill/?reqjob=32)) 사냥 콤보에서 딜의 중심으로 반복해서 나오는 기술은 **균열의 파도**이므로, 본 기술도 **본: 균열의 파도**부터 확인하면 됩니다. 2023년 BDFoundry 가이드는 이 본 기술을 쓰는 동안 전방 가드가 생긴다고 적었습니다. 배우기 전에 기술 창에 지금 적힌 효과를 읽어 보면 됩니다.

**소환: 파수꾼 테트**와 **소환: 파수꾼 고르**도 배워 둡니다. 흐름이 이 둘을 불러 공격합니다.
