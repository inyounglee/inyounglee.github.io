아래 내용은 **2026년 8월 기준 한국 검은사막 PC판**을 기준으로 정리했습니다. 하이퍼 부스트는 2026년 7월 29일 업데이트로 도입된 **신규·복귀 모험가 성장 지원 프로젝트**이며, 기존 모험가에게도 동일하게 적용됩니다. ([검은사막 GM노트][1])

# 검은사막 하이퍼 부스트 장비 스펙업 가이드

하이퍼 부스트의 최종 목표는 **공격력 + 방어력 합계(공방합) 750**입니다.

검은사막에서 공방합은 캐릭터의 전투력을 가늠하는 가장 기본적인 척도입니다. 사냥터 선택, 보스 레이드, 주간 콘텐츠 참여 여부를 판단할 때 이 수치를 먼저 확인하게 됩니다.

결론부터 말하면, 하이퍼 부스트의 핵심 장비 루트는 다음과 같습니다.

| 단계 | 핵심 목표 | 예상 공방합 | 증가 |
| --- | --- | ---: | ---: |
| 1 | 시즌 졸업 → 동(V) 투발라 세트 | 582 | — |
| 2 | 올비아 아카데미 → 군왕 무기 3종 | 616 | +34 |
| 3 | 알루스틴 의뢰 → 동(V) 카라자드 6부위 | 654 | +38 |
| 4 | 검은 사당 → 태고가 잠든 방어구 4종 | 694 | +40 |
| 5 | 추가 성장(가모스 개량, 강화 지원 등) | ~730 전후 | — |
| 6 | 모험일지·메인 의뢰 등 추가 콘텐츠 | **750** | — |

이 글에서는 위 표를 따라 **어디서 무엇을 받고, 어떤 순서로 진행하면 되는지**를 단계별로 정리합니다.

---

## 시작 전에 알아둘 것

### 공방합이란?

**공격력 + 방어력**을 더한 값입니다. 장비, 강화, 모험일지, 지식 등 다양한 요소가 반영되지만, 하이퍼 부스트 구간에서는 **장비 교체**가 공방합 상승의 대부분을 차지합니다.

### 하이퍼 부스트 혜택은 누구에게 적용되나?

2026년 7월 29일 이후 **기존 모험가도 동일한 혜택**을 받을 수 있습니다. 다만 이미 군왕 무기·태고 방어구·카라자드를 갖춘 경우, 일부 단계는 건너뛰거나 보상을 크론석 등으로 변환하는 선택지가 있습니다.

### 추천 사냥터 UI 활용

2026년 8월 업데이트부터 **최종 공격력 기준 ±50 범위**의 사냥터를 추천받을 수 있습니다. ([8월 6일 업데이트][2])

- 메뉴에서 사냥터 정보 → 추천 사냥터 확인
- 방어력은 추천 조건에 포함되지 않으므로, 공방합이 낮아도 공격력만 맞으면 추천될 수 있음
- 공격력이 부족해 의뢰가 안 보이면, 이전 단계 장비를 먼저 완료했는지 확인

---

## 1단계 — 시즌 캐릭터 생성과 졸업 (공방합 582)

하이퍼 부스트의 출발점은 **시즌 캐릭터**입니다.

### 1-1. 시즌 캐릭터 생성

캐릭터 생성 화면에서 **「시즌 캐릭터 생성」**을 선택합니다.

- 시즌 캐릭터는 전투 경험치 +1000% 등 시즌 전용 혜택을 받습니다.
- 레벨업과 전승/각성 의뢰만으로 시즌 패스를 진행할 수 있도록 개편되었습니다.

### 1-2. 시즌 패스 완료 → 동(V) 투발라 세트

2026년 7월 29일 이후 시즌 패스 보상이 크게 바뀌었습니다.

**이전:** 동 투발라 장비를 직접 제작·강화  
**현재:** 레벨 달성 시 **동(V) 투발라 장비를 직접 지급**

| 레벨 | 주요 보상 |
| --- | --- |
| 30 | 동(V) 투발라 장갑 |
| 52 | 동(V) 투발라 신발 |
| 53 | 동(V) 투발라 액세서리 지원 상자 (허리띠·귀걸이·반지) |
| 56 | 동(V) 투발라 투구 |
| 58 | 동(V) 투발라 갑옷 |
| 60 | 동(V) 투발라 무기·방패·각성무기·보조무기 |

동(V) 투발라 무기·방어구는 **동(V) 우두머리 장비와 동일한 표기 공격력·방어력**으로 상향 조정되었습니다. ([7월 29일 업데이트][3])

### 1-3. 시즌 졸업

시즌 패스를 모두 달성한 뒤 **[졸업하기]** 버튼을 누릅니다.

- 시즌 캐릭터가 일반 캐릭터로 전환됩니다.
- 그동안 쌓은 성장(레벨, 장비, 스킬)은 그대로 유지됩니다.
- 이 시점에서 **동(V) 투발라 풀세트**를 갖추게 되며, 공방합은 약 **582** 수준입니다.

> **팁:** 동 투발라는 이제 본캐용 최종 장비가 아닙니다. 이후 군왕·태고로 교체하므로, 완성된 동 투발라는 부캐나 월드 보스용으로 넘기는 것도 좋은 선택입니다.

## 2단계 — 올비아 아카데미와 군왕 무기 (공방합 616, +34)

시즌 졸업 후 **올비아 아카데미**를 수료하면 군왕 무기 제작 재료를 모을 수 있습니다.

### 2-1. 올비아 아카데미 입학

1. 가문 내 **레벨 60 이상** 캐릭터로 접속
2. 메뉴 → 모험 → **올비아 아카데미** → 길 찾기
3. 의뢰 타입 **「일반」**이 활성화되어 있어야 함
4. **[올비아 아카데미] 입학 절차** 의뢰 완료

입학 선물로 **동(V) 검은별 무기 선택 상자** 도전과제 보상을 받을 수 있습니다.

### 2-2. 동(V) 검은별 무기 5개 모으기

군왕 무기 제작에 필요한 검은별 무기는 **총 5개**입니다. 같은 부위는 **최대 2개**까지만 보유·제작할 수 있습니다.

| 획득 경로 | 내용 |
| --- | --- |
| 도전과제 | 메인 의뢰 일부 완료 시 **유(IV) 검은별 무기 상자** + **동(V) 검은별 무기 상자** |
| 입학 보상 | 동(V) 검은별 무기 선택 상자 |
| 전투 가문 보상 | 동(V) 검은별 무기 선택 상자, 유(IV) 검은별 무기 선택 상자 |
| 강화 | 유(IV) → 칠흑의 망치로 동(V) 강화, 또는 **어두운 별의 블랙스톤**으로 확정 강화 |

**도전과제 달성 조건 (택 1):**

- 메디아 메인 **「종말의 예언」** 완료
- 끝없는 겨울산 **「[겨울산] 아르옐리의 문 너머」** 완료
- 아침의 나라 **「[구미현전] 승산 선생의 비밀」** 완료
- 간소화 메인 **「[특별 성장] 푸가르의 비망록 11장」** 완료

올비아 아카데미 전투 강의를 진행하면 **칠흑의 망치, 황혼의 보석, 역류한 가모스의 심장** 등 추가 보상도 받습니다.

### 2-3. 태초의 불꽃 · 황혼의 보석

| 재료 | 획득 방법 |
| --- | --- |
| **태초의 불꽃** 1개 | 아침의 나라 월드 우두머리 인장 → 통합 재화·올비아 아카데미 인장 교환으로 **태초의 불씨 50개씩** → 가열하여 **태초의 불꽃** 제작 (100개 필요) |
| **황혼의 보석** 1개 | 올비아 아카데미 전투 강의 가문 보상 (**「[전투 강의] 낙오자」** 완료 시) |

### 2-4. 군왕 무기 3종 제작

재료를 모두 모았다면 **아침의 나라 — 아시산의 봉황 조각상**에서 제작합니다.

하이퍼 부스트 재료로 가능한 대표 제작식:

| 무기 | 방법 |
| --- | --- |
| 군왕 주무기 | 동(V) 검은별 주무기 + 동(V) 검은별 주무기 **또는** 동(V) 검은별 + **태초의 불꽃** |
| 군왕 각성무기 | 동(V) 검은별 각성무기 + 동(V) 검은별 각성무기 **또는** 동(V) 검은별 + **태초의 불꽃** |
| 군왕 보조무기 | 동(V) 검은별 보조무기 + **황혼의 보석** + **태초의 불꽃** (신규 제작식) |

군왕 무기 3종을 장착하면 공방합은 약 **616** (+34)입니다.

## 3단계 — 동(V) 카라자드 액세서리 (공방합 654, +38)

올비아 아카데미 입학을 마쳤다면, **벨리아 — 연금술사 알루스틴**에게 가세요.

### 3-1. 알루스틴의 지원 의뢰

가문당 1회, 아래 의뢰 6개를 완료하면 **동(V) 카라자드 6부위**를 한 번에 받을 수 있습니다.

| 의뢰 | 보상 |
| --- | --- |
| [알루스틴의 지원] 동(V) 카라자드 목걸이 | 목걸이 1 |
| [알루스틴의 지원] 동(V) 카라자드 허리띠 | 허리띠 1 |
| [알루스틴의 지원] 동(V) 카라자드 반지 I·II | 반지 2 |
| [알루스틴의 지원] 동(V) 카라자드 귀걸이 I·II | 귀걸이 2 |

**완료 조건 (모든 의뢰 공통):**

- 새벽의 정수 **10개**
- 뾰족한 흑결정 조각 **50개**

**재료 획득처:**

| 재료 | 주요 경로 |
| --- | --- |
| 새벽의 정수 | 올비아 아카데미 전투 가문 보상(총 60개), 통합 거래소 |
| 뾰족한 흑결정 조각 | 올비아 아카데미 주화 교환, 채집, 통합 거래소 |

알루스틴 의뢰 6개에 새벽의 정수만 **60개**가 필요합니다. 올비아 아카데미 보상만으로도 충분히 커버할 수 있어, 거래소 구매 없이 진행하는 것이 일반적입니다.

### 3-2. 이후 카라자드 성장

동(V) 카라자드 이후 강화·개량은 별도 콘텐츠입니다. 개량 재료(술잔, 새벽의 정수 등)는 [카라자드 액세서리 개량 재료 총정리](/blackdesert/2026/08/15/kharazad-reform-info/) 글을 참고하세요.

## 4단계 — 태고가 잠든 방어구 (공방합 694, +40)

하이퍼 부스트의 방어구 목표는 **태고가 잠든 등급 4부위**입니다. 검은 사당 토벌로 획득합니다.

### 4-1. 선행 의뢰 — 아침의 나라

1. **[아침의 나라] 태백에 드리운 그림자** 메인 의뢰 전체 완료  
   - 마그누스 의뢰 완료 후 이어서 진행하거나, 신규 캐릭터 생성 시 아침의 나라 분기 선택
2. **금돼지왕전 · 산군전 · 구미호전** 각각 완료  
   - 아침의 나라 의뢰는 **한 번에 하나씩**만 진행 가능

### 4-2. [흑정령의 지원] 의뢰 → 검은 사당 토벌

흑정령에게 **[흑정령의 지원]** 의뢰를 수주한 뒤, 검은 사당 — **동해도(개인)** 에서 토벌합니다.

| 의뢰 | 수주 조건 | 보상 (태고 방어구) |
| --- | --- | --- |
| 금돼지왕 팔재시니 | 공격력 305+, [금돼지왕전] 금광의 진실 완료 | **라브레스카의 투구** |
| 금돼지왕 구재시니 | 공격력 315+, [금돼지왕전] 금광의 진실 완료 | **아토르의 신발** (택1) |
| 산군 팔재시니 | 공격력 310+, [산군전] 우는 이 없는 호궁의 결말 완료 | **죽은신의 갑옷** |
| 구미호 팔재시니 | 공격력 315+, [구미호전] 다시 달벌로 완료 | **단의 장갑** (택1) |

> 의뢰가 목록에 안 보이면 **공격력 수치**와 **선행 의뢰 완료 여부**를 먼저 확인하세요. 2026년 8월 5일 이후 가문 내 조건 충족 캐릭터가 있으면 다른 캐릭터로도 수주 가능하도록 개선되었습니다.

### 4-3. 태고 방어구 주의사항

- 의뢰 지급 태고 방어구는 **통합 거래소 등록 불가**
- 필요 없을 경우 **가열하여 크론석 1,500개**로 변환 가능 (아이템 소멸)
- **아그리스의 정수(고대의 모루) 수치가 대폭 완화**되어 이후 강화가 빨라졌습니다

| 강화 단계 | 변경 전 | 변경 후 |
| --- | ---: | ---: |
| +0 → 갈망하는 | 12 | 8 |
| 갈망하는 → 일그러진 | 15 | 10 |
| 일그러진 → 침묵하는 | 20 | 12 |
| 침묵하는 → 울부짖는 | 50 | 20 |

4부위 장착 시 공방합은 약 **694** (+40)입니다.

## 5단계 — 하이퍼 부스트 이후 추가 성장 (~730 전후)

4단계까지 완료하면 공방합 **694** 근처입니다. 공식 GM노트 기준 **730 전후**부터 주요 콘텐츠(보스 레이드, 주간 던전 등)에 본격 참여할 수 있는 구간으로 안내됩니다. ([인벤 기획 기사][4])

### 5-1. 역류한 가모스의 심장 — 군왕 무기 개량 (+공격력)

**역류한 가모스의 심장**을 군왕 **주무기·각성무기**에 개량하면 **공격력 +3** (각 1회).

| 획득 경로 | 조건 |
| --- | --- |
| 도전과제 | 가문 누적 플레이 **100시간** + [지식] 도움의 대가 (마그누스 메인 완료) |
| 올비아 아카데미 | **[전투 강의] 전투학과 수료** 완료 |

→ **총 2개** 획득 가능. 주무기·각성무기에 각각 개량하면 **공격력 +6** 추가.

### 5-2. 카라자드 액세서리 강화 지원 — 엠마 바탈리의 기록일지

메뉴 → 모험(F5) → 모험일지 책장 → **「올비아 아카데미 성장일지」 — 엠마 바탈리의 기록일지**

| 강화 단계 | 지원 아이템 |
| --- | --- |
| 동(V) → 운(VI) | 확정 강화석 2개 + 하락 방지 망치 |
| 운(VI) → 우(VII) | 확정 강화석 2개 + 하락 방지 망치 |
| 우(VII) → 풍(VIII) | 확정 강화석 2개 |

선행 조건으로 **이고르 바탈리의 모험일지 5권** 완료가 필요합니다 (6단계에서 공방합 보너스도 제공).

### 5-3. 태고 방어구 강화 지원

- **갈망하는 태고의 결정** 지원 수량 상향 (올비아 주화 20개, 어둠의 틈 10개, 불멸의 나락 10개 등)
- 아그리스 정수 최대치 도달 시 **확정 강화** 가능

하이퍼 부스트 핵심 장비(군왕·카라자드·태고)를 마친 뒤, 아래 **추가 콘텐츠**를 진행하면 공방합 **750**에 도달합니다.

## 자주 막히는 구간과 해결법

### 「의뢰가 목록에 안 보여요」

1. **공격력**이 수주 조건(305/310/315)을 충족하는지 확인  
2. **선행 메인·전투 의뢰** 완료 여부 확인  
3. 의뢰 타입 **「일반」** 활성화 여부 확인  
4. 흑정령 **[흑정령의 지원]** 의뢰를 먼저 수주했는지 확인 (검은 사당)

### 「검은별 무기가 5개가 안 모여요」

- 도전과제(메인 일부 완료) + 입학 보상 + 전투 가문 보상 + 유→동 강화를 **모두** 확인  
- 같은 부위 검은별은 **최대 2개** 제한 — 부위 배분을 미리 계획

### 「새벽의 정수가 부족해요」

- 알루스틴 의뢰: 60개 (올비아 보상으로 충분)  
- 이후 카라자드 강화·개량: [카라자드 개량 가이드](/blackdesert/2026/08/15/kharazad-reform-info/) 참고  
- 거래소 구매도 가능 (상한가 1억 은화)

### 「이미 장비가 있어요 — 하이퍼 부스트를 다시 받을 수 있나요?」

- 가문당 1회 의뢰·보상이므로 **중복 수령 불가**  
- 불필요한 지원 장비는 **크론석 변환** 가공식 활용 (태고 방어구 1,500개, 고대의 블랙스톤 1,000~2,000개 등)

## 정리

하이퍼 부스트는 예전의 **「동 투발라 → 유 우두머리 교환 → 카프라스 → 태고 제작」** 같은 긴 우회로를 대폭 줄였습니다.

| 과거 | 하이퍼 부스트 |
| --- | --- |
| 동 투발라 직접 제작·강화 | 시즌 패스로 **동(V) 투발라 즉시 지급** |
| 검은별·태초·황혼 각자 파밍 | **올비아 아카데미** 보상으로 대부분 해결 |
| 카라자드 제작·강화 반복 | **알루스틴 의뢰**로 동(V) 6부위 즉시 |
| 태고 방어구 장기 제작 | **검은 사당** 토벌 4회로 4부위 |

핵심만 기억한다면:

1. **시즌 졸업**으로 기본 장비(582)  
2. **올비아 아카데미**로 군왕 무기(616)  
3. **알루스틴**으로 카라자드(654)  
4. **검은 사당**으로 태고(694)  
5. **모험일지·메인**으로 750  

순서대로 진행하면 됩니다. 공방합 750은 끝이 아니라 **에다니아·주간 레이드·카라자드 상위 단계**로 이어지는 출발점입니다.
