# 노스토스의 별 제작 가이드

**노스토스의 별**을 **야영지**에 장착하면 **주거지·장원**으로 이동할 수 있습니다. 사냥터 야영지 ↔ **장원 창고·가구 버프** 왕복에 쓰입니다.

---

## 효과 요약

| 항목 | 내용 |
| --- | --- |
| 사용 | **야영지**에 장착 후 **주거지·장원** 선택 이동 |
| 재사용 | **30분** (가문 캐릭터별) |
| 복귀 | 장원·주거지에서 나오면 **야영지 위치**로 귀환 |
| 거래 | **불가** (가문 귀속) |

> 거점/점령전·장미 전쟁 중 **불가**. 대여 만료 **장원 불가**.

---

## 1단계 — 하위 재료 (채집)

6종 채집(맨손·물뜨기·우유 제외)으로 **희귀 재료** 드랍. **모채획·숙련도**에 따라 확률·개수(1~3) 변동.

| 채집 | 하위 재료 (×1,000 목표) |
| --- | --- |
| **호미** | 갈라진 땅의 파편 |
| **벌목** | 메마른 나무 조각 |
| **수액** | 투명한 생명의 정수 |
| **채광** | 흐릿한 광맥의 파편 |
| **도축** | 희미한 야생의 혼 |
| **무두질** | 빛바랜 자연의 외피 |

> **숙련도 ~2,700+** 부근부터 2개 이상 채집이 안정적. **무화과 파이·생명 연금석·라라 홍차** 등 모채획 버프 권장.

### 추천 채집 장소

커뮤니티에서 자주 언급되는 **재료별 대표 거점**입니다. 숙련도·세팅·무게 관리 방식에 따라 달라질 수 있습니다.

| 채집 | 재료 | 추천 장소 | 비고 |
| --- | --- | --- | --- |
| **호미** | 갈라진 땅의 파편 | **베어 마을** — 야생 들풀 | 약초 종류가 많아 무거워지기 쉬움. 베어 마을 **주거지 + 공헌도 대여 보관함**이면 창고 접근이 편함 |
| **벌목** | 메마른 나무 조각 | **트렌트 마을** — 소나무 원목 | **창고지기**가 바로 옆 — 무게 찰 때마다 보관하기 좋음 |
| **수액** | 투명한 생명의 정수 | **트렌트 마을** — 소나무 수액 | 벌목과 동일하게 트렌트 마을 창고 활용 추천 (**주의: 오직 '식물류 수액 채취'를 통해서만 확률적으로 획득할 수 있습니다.**) |
| **채광** | 흐릿한 광맥의 파편 | **순교자의 안식처** — 사암 등 | 돌탑 밀집, **제자리 R 연타** 채집. 고갈 시 옆 돌탑·채널 이동 |
| **도축** | 희미한 야생의 혼 | **베어 마을** — 사슴 | 보물 재료만 목적이면 **도축·무두질·수액**을 한 지역에서 병행하기도 함 |
| **무두질** | 빛바랜 자연의 외피 | **베어 마을** — 사슴 / **린치 목장** — 양 | |

> **상세 루트·대체 장소·무게 관리 팁** — 검은사막 인벤 **만두집아들**님 글: **[노스토스의 별 추천 채집 장소](https://www.inven.co.kr/board/black/3584/58813)**

---

## 2단계 — 중간 재료 (간이연금)

각 하위 재료 **1,000개** + **자연의 정수 100개** → 간이연금

| 하위 ×1,000 + 자연의 정수 ×100 | 결과 |
| --- | --- |
| 갈라진 땅의 파편 | **땅의 결정체** |
| 메마른 나무 조각 | **세월의 나무** |
| 투명한 생명의 정수 | **생명의 정수** |
| 흐릿한 광맥의 파편 | **광맥의 결정** |
| 희미한 야생의 혼 | **야생의 혼** |
| 빛바랜 자연의 외피 | **자연이 깃든 외피** |

---

## 3단계 — 최종 조합

중간 재료 **6종**을 **야즈의 조합 주머니**(또는 일반 가방, **자동 정렬 해제**) **조합식**에 배치 → **노스토스의 별**

---

## 사용 방법

1. 사냥터 등에 **야영지** 설치
2. 야영지 UI에서 **노스토스의 별** 장착 (설치 지점 **근처**에서만)
3. 사용 → **주거지·장원** 선택 → 이동
4. **30분 쿨** — 로그아웃해도 감소

---

## 팁

- **고슴도치·대량 채집** 적용되나 확률 **매우 낮음** — 장기 생활 프로젝트.
- 채광(순교자의 안식처)은 **거친 석재·구리·아연** 등 부산물이 많아 **무게 관리**가 중요합니다. **크로그달로의 둥지**로 말에 분산 적재하거나, 메이드·창고를 병행하는 방식이 커뮤니티에서 자주 언급됩니다.
- **플로린 — 발렌타인** **[집으로]** 의뢰로 칭호 획득 가능.
