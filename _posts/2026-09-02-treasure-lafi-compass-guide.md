# 라피 베드마운틴의 개량형 나침반 제작 가이드

**개량형 나침반**은 가방에 지니면 **사막·대양에서도 영구 나침반** 효과를 누리며, **[파티] 집결**로 동의한 파티원을 **본인 위치로 순간이동**시킬 수 있습니다. 거점·쟁 길드에서 필수급 보물입니다.

---

## 효과 요약

| 항목 | 내용 |
| --- | --- |
| 나침반 | 사막·대양 **위치 표시** (영구) |
| 집결 | 파티원 **본인 위치로 소환** |
| 재사용 | 집결 발동 후 **약 10시간** (게임 내 10분 제한 별도) |
| 거래 | **불가** (가문 귀속) |

### 사용 제한

- 부대 소속·점령/거점전·붉은 전장·수용소 **불가**
- 말/낙타/당나귀 외 탑승물 탑승 시 **불가**
- **무역품** 소지 시 **불가**
- 집결 후 **10분** 경과·로그아웃·서버 이동 파티원 **소환 불가**

---

## 필요 재료 (6종)

| 재료 | 수급 |
| --- | --- |
| **개량형 나침반 부품 ×3** (서로 다른 3종) | 아래 표 참고 |
| **핏빛 루비** | 가공·거래소 |
| **물빛 사파이어** | 가공·거래소 |
| **금빛 토파즈** | 가공·거래소 |

### 나침반 부품 3종 (감정 후 이름)

| 부품 | 드랍처 |
| --- | --- |
| **부품 1 (아크만)** | **아크만 사원** — 아크만 정예 수호자 등 |
| **부품 2 (보드칸)** | **히스트리아 폐허** — 보드칸 (상대적으로 잘 나옴) |
| **부품 3 (엘텐)** | **히스트리아 폐허** — 엘텐, 발텐 (**드랍 매우 낮음**) |

> 드랍 직후 이름은 모두 **「개량형 나침반 부품」** 으로 같습니다. **고대의 틈 — 아인 그레이드**에게 **감정**해야 종류를 확인할 수 있습니다.

---

## 제작 순서

1. 부품 3종 + 보석 3종을 **공식 조합식** 위치에 배치
2. **조합(+)** — 감정 전 아이템도 **종류·위치**만 맞으면 조합 가능
3. **라피 베드마운틴의 개량형 나침반** 완성

---

## 팁

- **엘텐** 부품이 병목입니다. 히스트리아 장기 파밍·풍경화·이벤트 사냥터(데키아, 가이핀라시아 등) 활용.
- 본인에게 직접 이득보다 **파티원 소환**용 — 쟁 길드·거점전 연습에 가치가 큽니다.
- **[보물의 진정한 주인]** 의뢰 완료 시 걸작 가구·**북극성** 칭호.
