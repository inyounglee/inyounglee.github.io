# 검은사막 펫작 가이드

꺼낸 반려동물이 떨어진 아이템을 줍습니다. **자동 룻팅**이 사냥 편의의 전부라고 해도 과장이 아닙니다. 세대가 낮아도 소환만 하면 룻은 됩니다. 세대는 **줍는 속도**와 **고유 기술**을 올립니다.

```
입문     아무 세대 5마리 소환
저렴     4세대 5마리 (교환)
최종     4세대 4마리 + 5세대 대장 1마리
```

한 번에 꺼낼 수 있는 펫은 **5마리**입니다. 왼쪽 위 **반려동물 목록**에서 하나씩 꺼내거나, **Alt+** 단축키 설정으로 미리 그룹 지정한 펫 그룹을 바로 꺼낼 수 있습니다. 맡겨 두면 룻이 멈춥니다.

---

## 빠르고 저렴하게 {#cheap}

목표는 **4세대 5마리를 꺼내는 것**입니다. 고유 기술(전투 경험치, 무게, 특기)은 있으면 좋고, 없어도 룻은 됩니다.

| 방법 | 비용 감각 | 비고 |
| --- | --- | --- |
| 이벤트·접속·시즌 보상 상자 | **거의 0** | 가장 빠름. 세대가 제각각이면 교환 |
| 하위 세대 여러 마리를 **교환** | 은화 거의 없음 (펫만 소모) | 같은 종류를 모아 세대를 올림 |
| 펄 상점 4세대 | 펄 | 종류·기술을 고르고 싶을 때 |
| 거래소 펫 | 시세 (수천만~) | 거래 가능 펫만. 매물은 들쭉날쭉 |

세대 올리기(최대 **4세대**)는 NPC가 아니라 **반려동물 목록의 교환**입니다. 꺼낸 펫은 먼저 맡긴 뒤, 목록에서 **교환**을 누릅니다. 같은 교환 유형끼리 **2~5마리**를 넣고 외형·기술을 고르면 됩니다. ([공식 — 반려동물](https://www.kr.playblackdesert.com/ko-KR/Wiki?wikiNo=180))

교환은 **5세대 훈련 전에** 끝내세요. 5세대로 올린 펫은 **교환이 잠깁니다.** 외형·기술을 바꾸고 싶으면 4세대에서 교환한 뒤 훈련합니다. 외형 변경권은 5세대에도 쓸 수 있습니다.

소환 확인:

1. 왼쪽 위 **반려동물 목록**에서 하나씩 꺼내거나, **Alt+** 단축키로 지정해 둔 펫 그룹을 꺼내기
2. 자동으로 전리품을 줍는지 한 바퀴만 확인
3. 고유 기술·특기는 펫 창에서 아이콘으로 확인

이 단계면 [고수익 사냥터](/blackdesert/2026/09/22/hyper-boost-grind-spots-guide/)를 돌아도 룻은 따라옵니다.

## 최종 단계 — 5세대 대장 한 마리 {#final}

5세대는 **대장 한 마리**만 의미가 있습니다. 대장이 아닌 5세대는 대장과 같이 꺼낼 수는 있지만, **능력치는 4세대와 같습니다.** 은화를 다섯 번 쓸 필요가 없습니다.

### 대장 효과

- 대장이 꺼내져 있으면, 같이 꺼낸 모든 펫의 **전리품 줍기 시간이 15% 감소**합니다. (`우리들의 골목대장!`)
- 대장 자신의 **고유 기술 레벨 +1** (예: 전투 경험치 4% → 5%, 생명력 100 → 125)
- 특기(자동 낚시 시간 감소, 채집량 증가 등)는 변하지 않습니다.
- 훈련해도 **외형은 그대로**입니다.

대장은 **한 마리만** 임명할 수 있습니다. 펫을 맡긴 상태에서 반려동물 메뉴의 **왕관**을 누르면 임명·변경됩니다.

### 제왕의 깃털

5세대 훈련에는 **제왕의 깃털** 1개가 필요합니다. 가공(L) → **간이 연금**.

| 재료 | 수량 | 구하는 법 |
| --- | --- | --- |
| **성장의 시약** | 10 | 그믐달 관리자 상점, 개당 **6,000만** → 합 **6억** |
| **마력의 파편** | 40 | 봉인된 검은 마력의 수정 또는 검은 마력의 수정을 가열(L) |
| **상급 가벼운 깃털** | 800 | 가벼운 깃털·부드러운 페리의 깃털 등을 솎아내기(L) |

그믐달 상점은 화면 오른쪽 위 **돋보기(NPC 찾기)** 검색창에 **그믐달 관리자**를 치면 됩니다. 상급 가벼운 깃털은 나반 초원 페리·페리카 무두질 후 솎아내기가 흔합니다. 솎아내기 수련 지식은 의뢰 받은 일(O) → 추천 → `[생활][자격증] 수련 생활인`.

대략 비용: **시약 6억은 확정**. 파편·깃털은 직접 구하면 수천만~억 단위, 거래소면 시세만큼 더 붙습니다. 이벤트 깃털이 있으면 체감이 크게 내려갑니다.

### 훈련 절차

1. 흑정령 `/` → **`[반려동물] 다툼의 이유`** 연속 의뢰 (60레벨 이상, 추천 의뢰. 안 보이면 의뢰 타입에서 [생활] 켜기)
2. 카마실비아 **지혜의 고목 · 오비 벨렌**(또는 아래 대도시 NPC) → 반려동물 5세대 훈련. 위치는 화면 오른쪽 위 **돋보기(NPC 찾기)**에 이름을 검색하면 됩니다. ([공식 — NPC 찾기](https://www.kr.playblackdesert.com/ko-KR/Wiki?wikiNo=248))

| 마을 | NPC |
| --- | --- |
| 벨리아 | 풀비오 |
| 하이델 | 멜리사 브레디, 푸이아 |
| 칼페온 | 프레지오 |
| 알티노바 | 드로쉬 |
| 지혜의 고목 | 오비 벨렌 |

3. **10레벨 이상 4세대** + 제왕의 깃털 → 훈련 (확정 성공)
4. 펫 메뉴에서 **대장 임명** 후 5마리 모두 소환

훈련 뒤에는 교환이 불가능합니다. 대장으로 쓸 펫의 고유 기술·외형을 4세대에서 고른 뒤 올리세요.
