# 에벤루스의 놀 제작 가이드

**에벤루스의 놀**을 **에페리아 중범선**에 장착하면 **쾌속 순항을 지구력 소모 없이 1회 추가** 사용할 수 있으며, 추가 순항 **이동 거리 +50%** 입니다.

---

## 효과 요약

| 항목 | 내용 |
| --- | --- |
| 장착 | **에페리아 중범선** |
| 효과 | 쾌속 순항 **+1회** (지구력 0), 거리 **+50%** |
| 조건 | 가속도 **135%+**, 제동 **160%+** |
| 거래 | **불가** |

> **대안 구매** — 까마귀 주화 **200만** (레마섬·랏항구·까마귀 둥지 교환원)

---

## 최종 조합

| 재료 | 획득 |
| --- | --- |
| **문양이 새겨진 놀** | 아래 「놀」 루트 |
| **에벤루스** | 오킬루아의 꽃 **1,000** + 오킬루아의 눈물 **1** → **간이연금** |

→ 두 재료 **가방 조합** → **에벤루스의 놀**

---

## 1. 문양이 새겨진 놀

| 단계 | 내용 |
| --- | --- |
| 1 | **바다악어** 사냥 → **이끼에 뒤덮인 지도** |
| 2 | **리비니아**(까마귀 둥지) — **이끼 제거 용액** 구매 → **간이연금** → **찢어진 보물지도 조각** (9종, **서로 다른** 9개) |
| 3 | 9조각 **조합** → **어느 선원의 보물지도** (극低 확률로 2번에서 바로 완성 지도) |
| 4 | 지도 **의뢰 진행** → **어느 선원의 보물상자** |
| 5 | 상자 개봉 → **약 1%** 확률 **문양이 새겨진 놀** |

---

## 2. 에벤루스

| 재료 | 수급 |
| --- | --- |
| **오킬루아의 꽃 ×1,000** | 물물교환, 까마귀 둥지 상점, 보물상자 등 |
| **오킬루아의 눈물 ×1** | 까마귀 둥지 상점 (**10만 주화**) |

→ **간이연금** → **에벤루스**

---

## 팁

- **찢어진 보물지도 조각**은 **같은 모양 중첩 불가** — 9종 각 1개씩 필요.
- 놀 드랍이 RNG 병목; 꽃 1,000개·주화 구매는 상대적으로 확정에 가깝습니다.
- **[보물의 진정한 주인]** → 걸작 가구·**함장** 칭호.
