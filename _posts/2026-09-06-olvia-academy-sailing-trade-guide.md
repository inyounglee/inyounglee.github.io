# 올비아 아카데미로 항해·교역 시작하기

항해·교역은 **대형 선박 + 물물교환**이 핵심입니다. 올비아 아카데미 항해 강의만 따라가면 **에페리아 고속정 → 에페리아 경범선**까지 받고, **물물교환 10회**로 교역 입문까지 끝낼 수 있습니다.

배가 없으면 **[까마귀의 둥지] 연속 의뢰**(엠마 기록일지 2장)도 같이 막힙니다. 올비아 기간이면 이 강의로 배를 **공짜**로 받고, 아니면 **통합 거래소**에서 선박 등록증을 사면 됩니다. ([까마귀의 둥지 의뢰 가이드](https://blueforget.tistory.com/263))

```
입학(60+) → 필라베르토 수강 신청
  → 선박 지원 I (고속정) 등록
  → 발레노스 군도 지식
  → 선박 지원 II (경범선) + 물물교환 10회
  → 수리 자재 · 선원 · 해상 몬스터 · 수료
  → (선택) 까마귀의 둥지 연속 의뢰와 병행
```

## 시작 조건

| 항목 | 내용 |
| --- | --- |
| 레벨 | **60+** 캐릭터 |
| 선행 | **올비아 아카데미 입학** 완료 (진행 중인 기수) |
| 의뢰 타입 | **일반** 의뢰 ON |
| 횟수 | 항해 강의 = **기수당 가문 1회** · 선박 지원 II는 **가문당 1회**(기수 무관) |

### 강의 여는 법

1. 우측 상단 **올비아 아카데미** 버튼 → **항해/교역** 과목 선택  
2. 또는 올비아 아카데미에서 **필라베르토 팔라시**에게 `[항해 강의] 필라베르토에게 수강 신청하기` 수주  
3. 가문 의뢰이므로 **아카데미에 캐릭터 1명 주차**하고, 먼 바다는 **부캐**로 돌리면 편합니다.

## 1. 고속정 받기 — 선박 지원 I

`선박 등록으로 바다로 향할 준비를` 진행 중 **로도비카**에게 **`[항해 강의] 선박 지원 I`**이 열립니다.

1. **선박 등록증: 에페리아 고속정** 수령  
2. 등록증 **우클릭** → 안내되는 **선착장**(나루터지기)으로 이동  
3. 나루터지기 → **선착장** → **선박 등록** → 이름 입력  
4. 등록한 배 선택 → **찾기**로 소환 후 탑승

고속정은 **이동·입문용**입니다. **물물교환(교역)은 대형 선박**만 가능하므로, 다음 단계의 **경범선**이 필요합니다.

---

## 2. 발레노스 군도 지식

`[항해 강의] 발레노스 군도를 향하여`는 발레노스 근해 섬들의 **지식**을 요구합니다.

- 이미 섬 지식작이 끝난 가문은 **바로 완료**되는 경우가 많습니다.  
- 미개척이면 고속정으로 섬을 돌며 지식을 채워야 해서 **시간이 가장 많이 드는 구간**일 수 있습니다.  
- 월드맵에서 섬을 열고, 섬에 상륙·대화·탐험로 지식을 확보하세요.

> **참고 (4/15 패치):** 이 의뢰 보상에서 **에페리아 경범선**은 빠졌습니다. 경범선은 아래 **선박 지원 II**로 받습니다.

---

## 3. 교역 시작 — 물물교환 10회 + 경범선

핵심 구간입니다. `[항해 강의] 물물교환으로 교역의 시작을`를 수주하면:

### 3-1. 선박 지원 II (경범선)

- 진행 중 **로도비카**에게 **`[항해 강의] 선박 지원 II`** 수주  
- 보상: **선박 등록증: 에페리아 경범선**  
- 고속정과 같이 **선착장에 등록**  
- **가문당 1회**. 1기 때 `발레노스 군도를 향하여`로 경범선을 이미 받은 가문은 **추가 수령 불가**

경범선(대형 선박)을 등록해야 물물교환이 열립니다.

### 3-2. 물물교환 UI 여는 법 · 조건 설정

처음이면 **메뉴에서 검색**하는 편이 빠릅니다.

1. **메뉴(ESC)** → 검색창에 **「물물교환」** 입력 → **물물교환** / **물물교환 정보** 실행  
   - 또는 메뉴 → **생활 → 물물교환**  
   - 월드맵(M) 좌상단 **물물교환 정보**로도 열 수 있습니다.
2. UI에서 **교환 조건(필터)**을 먼저 맞춥니다. (입문 추천 설정)

| 설정 | 추천 |
| --- | --- |
| **단계** | **1단계**만 표시 (육지 재료 → 1단계 교역품) |
| **보유/가능** | **내가 가진 재료로 교환 가능한 항목**만 보이게 |
| **지역** | **벨리아·발레노스 근해** 등 가까운 섬 위주 |
| **정렬** | 거리·교섭력 소모가 낮은 것부터 |

3. 목록의 **받을 교역품**을 클릭하면 해당 섬으로 **카메라/길 안내**가 잡힙니다.  
4. 교환에 필요한 **줄 재료**가 없으면 → **통합 거래소**에서 해당 육지 재료를 검색해 구매합니다.  
5. 재료는 **캐릭터 가방이 아니라 선박 가방**에 있어야 교환됩니다.

### 3-3. 교환 물품 — 거래소에서 사기

강의 10회는 **벨리아 근해 0→1단계**만 반복하면 충분합니다.

| 순서 | 할 일 |
| --- | --- |
| 1 | 물물교환 UI에서 **1단계** 교환을 골라 **필요 재료명** 확인 |
| 2 | **통합 거래소** → 재료명 검색 → 시세 맞춰 구매 (무게·수량 여유 있게) |
| 3 | 선착장에서 **화물 적재**로 선박 가방에 넣기 (탑승 중에도 가방↔탑승물 이동 가능) |
| 4 | 길 안내 따라 섬 도착 → **정박** → 물물교환 |
| 5 | 같은 방식 **10회** 반복 후 필라베르토에게 완료 |

> 가방에만 넣고 배에는 안 실으면 **교환이 안 됩니다**. 반드시 **화물 적재**를 확인하세요.

### 3-4. 물물교환 10회 — 요약

| 팁 | 내용 |
| --- | --- |
| 어디? | **벨리아 근해** **0단계 → 1단계** 섬 왕복 |
| 몇 회? | **10회** (동일 루트 반복 OK) |
| 재료 | **통합 거래소**로 육지 재료 구매 → 1단계 교환 |
| 적재 | 선착장 **화물 적재** |
| 길 안내 | ESC 검색 **물물교환** · UI 항목 클릭 |

```
ESC → 「물물교환」 검색 → 1단계 필터
  → 필요 재료를 거래소에서 구매
  → 화물 적재 → 섬 정박 → 교환 (×10)
  → 필라베르토에게 완료
```

물물교환은 **바탈리 범선부터 증축하는 대형 선박** 계열에서만 됩니다. 경범선 등록을 빼먹지 마세요.

## 4. 식량 · 함포·포탄 · 충각 · 선상 수리

해상 몬스터·항해 중 전투는 **함포** 또는 **충각**으로 처리합니다. 입문·강의용 경범선은 **충각만으로도** 충분합니다. 먼 바다 나가기 전 **식량·포탄**을 꼭 확인하세요.

### 4-1. 선상에서 식량 채우기

배가 바다에 떠 있는 상태에서도 가방에 있는 **정식**으로 식량을 채울 수 있습니다.

1. **내 아이템 찾기(Ctrl+F)** → **「정식」**으로 검색  
2. **세렌디아 정식 / 칼페온 정식 / 메디아 정식** 등을 가방으로 가져옵니다. (창고·거래소에서도 준비 가능)  
3. 배에 탑승한 뒤 **선박 정보(F5)** 를 엽니다.  
4. **식량** 항목의 **「+」** 버튼을 눌러 정식을 넣고 식량을 채웁니다.

| 방법 | 설명 |
| --- | --- |
| **선상 (F5 +)** | Ctrl+F로 정식 검색 → 선박 정보에서 직접 충전 · 바다 한가운데에서도 가능 |
| **나루터지기 보급** | 선착장에서 **보급**으로 채우기 · **은화 기준 더 저렴**해서 출항 전엔 이쪽 권장 |

> 출항 전에는 **나루터지기 보급**으로 식량·포탄을 채우고, 항해 중 식량이 바닥날 때만 선상 **정식 +** 로 보충하는 편이 효율적입니다.

### 4-2. 포탄(함포탄) 보급 · 함포 사용

1. **선착장**에서 배를 선택한 뒤 **보급**으로 **식량 + 포탄**을 채웁니다.  
   - 포탄은 보통 **1발당 은화**로 보급됩니다. (대형 선박은 보급 UI로 적재)
2. **일반 에페리아 경범선**은 조타석에 앉은 채로는 함포를 못 쏘는 경우가 많습니다.  
   - 조타에서 **하차** → 갑판의 **함포**로 다가가 **상호작용** → 조준 후 **발사**  
3. **개량형**·상위 선박은 조타 중 **일제사격** 등으로 좌·우현 함포를 마우스로 쏠 수 있습니다.  
4. 포탄이 없으면 함포가 나가지 않으니, 먼 바다 나가기 전 **보급**을 확인하세요.

### 4-3. 함포 없이 잡기 — 충각 (운항 중 F)

포탄이 없거나 함포가 익숙하지 않으면 **충각**으로 잡으면 됩니다.

| 항목 | 내용 |
| --- | --- |
| 조작 | **운항 중 F** (항해 기술 **충각**) |
| 피해 | **옆·뒤**에서 박으면 피해가 더 큼 (정면보다 유리) |
| 횟수 | 헤카루 등 입문급은 대략 **3~4번** 박으면 처치되는 편 |
| 주의 | 충각은 **스태미나**를 소모합니다. 스태미나가 없으면 기술이 안 나갑니다. |

```
조타로 접근 → 옆/뒤로 각도 잡기 → F(충각) 반복 3~4회
```

### 4-4. 내구도 50% 이하 · 선상 수리 (F6)

| 증상 | 대응 |
| --- | --- |
| 선박 **내구도 50% 이하** | 배가 **느려집니다**. 전투·이동 전에 수리하세요. |
| 수리 위치 | 선상 **돛대 뒤쪽 벽** 근처로 이동 |
| 수리 조작 | 근처에 가면 **수리(F6)** 상호작용이 뜹니다 → **F6**으로 수리 |

수리에는 강의에서 만드는 **함선 수리 자재** 등이 필요합니다. 자재가 없으면 아래 5장의 **재료 지원**·제작을 먼저 하세요.

## 5. 수리 자재 · 선원 · 해상 처치

### 함선 수리 자재

- `함선 수리 자재로 안전한 항해를`  
- **로도비카**의 **`[항해 강의] 재료 지원`**으로 **물푸레 나무 합판** 지원을 받을 수 있습니다.  
- 합판이 부족하면 **장작 패기(가공)**로 보충합니다. (공략 팁: 합판 2개분 장작 패기)

### 선원

- `선원에 관하여` — 선원 고용·배치 UI 안내를 따라가면 됩니다.

### 해상 몬스터 (시간 절약)

| 의뢰 | 목표 | 위치 팁 |
| --- | --- | --- |
| 병든 헤카루의 위협 | 병든 헤카루 **1** | 항해학 교수(필라베르토) **바로 앞** 바다 |
| 어린 해왕류의 위협 | 어린 해왕류 **3** | **오킬루아** 아래 · **리스즈 섬** 왼쪽 구역 |
| 증명, 헤카루의 처치 | 성체 헤카루 **1** | 대양 · **오킬루아 앞바다** 등 (안내 마커 기준) |

- **배 전투:** 위 **충각(F)** 또는 함포  
- **수중:** **채이**로 내려가 처치해도 됩니다.  
- 가문 의뢰이므로 처치 후 **부캐로 완료/다음 수주**해도 됩니다.

## 6. 엠마 기록일지 · 까마귀의 둥지와 함께 진행

[엠마 바탈리의 기록일지](https://www.inyounglee.kr/blackdesert/2026/09/06/emma-bartali-journal-guide/) **2장**은 `[까마귀의 둥지] 까마귀의 용병` 완료가 조건입니다. 이 연속 의뢰는 **먼 바다 섬**에서 진행되므로 **배가 필수**입니다.

| 상황 | 배 구하는 법 |
| --- | --- |
| **올비아 아카데미 기간** | 이 포스트의 **항해/교역 강의**로 고속정·경범선을 **무료** 수령 |
| 배가 이미 있음 / 아카데미 외 | **통합 거래소**에서 선박 등록증(바탈리 범선·에페리아 경범선 등) 구매 후 선착장 등록 |

의뢰 상세·NPC 동선은 **[까마귀의 둥지 연속 의뢰 가이드](https://blueforget.tistory.com/263)** 를 보세요. 항해 강의로 배를 받은 뒤, 같은 출항으로 **물물교환 10회**와 **까마귀의 둥지**를 이어서 돌리면 동선이 아깝지 않습니다.

## 7. 유물·광명석 — 항해 시작 & 최종 추천

**2026년 9월 2일** [생활 장비 통합](https://www.kr.playblackdesert.com/ko-KR/News/Detail?groupContentNo=16141&countryType=ko-KR) 이후, 유물은 **옷이 아니라 생활 통합(기본 생활 세팅) UI**에 장착합니다. 가문 공유이며, **항해/교역** 활동을 할 때 해당 탭 세팅이 자동 적용됩니다.

| 항목 | 내용 |
| --- | --- |
| 장착 위치 | **생활 통합 UI** → **항해/교역** 슬롯 (의상·도구와 같은 생활 장비 창) |
| 유물 | **세스라** (항해 경험치·숙련도·교역 경험치) · 공통 **생활 경험치/숙련도** · **마가한** |
| 광명석 | 유물에 **풀의 광명석 / 오색빛**만 생활 조합에 사용 (불·땅·바람은 생활 조합에서 제외) |
| 적용 | 항해·물물교환 등 **실제 활동**에 맞춰 자동 반영 · 가문 내 전 캐릭터 공유 |

상세 원문: 공식 [광명석 조합식](https://www.kr.playblackdesert.com/ko-kr/Wiki?wikiNo=273) · [9/2 업데이트](https://www.kr.playblackdesert.com/ko-KR/News/Detail?groupContentNo=16141&countryType=ko-KR)

> **팁:** 광명석 추출은 개당 은화가 듭니다. 처음엔 가진 유물에 광명석을 먼저 맞추고, 나중에 유물만 바꿔도 됩니다. ①·②는 첫 유물, ③·④는 둘째 유물에 나눠 끼워도 조합이 발동합니다. **항해사 옷에는 더 이상 유물을 꽂지 않습니다.**

### 7-1. 단품 효과 (항해·교역)

| 아이템 | 효과 |
| --- | --- |
| **세스라의 유물 — 항해 경험치** | 항해 경험치 **+5%** |
| **세스라의 유물 — 항해 숙련도** | 항해 숙련도 **+10** |
| **세스라의 유물 — 교역 경험치** | 교역 경험치 **+5%** |
| **세스라의 유물 — 생활 경험치/숙련도** (공통) | 장착한 생활(항해/교역)에만 경험치·숙련도 적용 |
| **풀의 광명석 : 미지** | 항해 경험치 **+3%** |
| **풀의 광명석 : 수완** | 교역 경험치 **+3%** |
| **풀의 광명석 : 파랑** | 항해 숙련도 **+5** |
| **오색빛 광명석** | 고급 조합 4번째 칸용 |

### 7-2. 항해·교역 광명석 조합식

| 조합명 | 효과 | 광명석 |
| --- | --- | --- |
| **흔들흔들 조타수** | 항해 경험치 **+5%** | 미지 ×3 |
| **하늘과 바다의 경계로** | 항해 경험치 **+8%** | 미지 ×4 |
| **너울빛 동행** | 항해 경험치 **+16%** | 미지 ×3 + **오색빛** |
| **저울의 주인** | 교역 경험치 **+5%** | 수완 ×3 |
| **물물교환 장학생** | 교역 경험치 **+8%** | 수완 ×4 |
| **교섭의 달인** | 교역 경험치 **+16%** | 수완 ×3 + **오색빛** |
| **선원의 힘줄** | 항해 숙련도 **+8** | 파랑 ×3 |
| **녹이 슨 닻** | 항해 숙련도 **+15** | 파랑 ×4 |
| **위대한 물결** | 항해 숙련도 **+30** | 파랑 ×3 + **오색빛** |
| **바다의 포옹** | 항해 경험치 **+10%** · 교역 경험치 **+10%** · 항해 숙련도 **+45** · 인어의 소망 III | **미지 + 수완 + 파랑 + 오색빛** |
| **선택과 집중 : 항해** | 항해 경험치 **+35%** · 항해 숙련도 **−500** | 미지 ×2 + **풀의 광명석 : 야생** + 오색빛 |

> 9/2 이후 생활 조합은 **풀의 광명석·오색빛만** 사용합니다. 예전 `바람의 광명석 : 머리` 자리는 **`풀의 광명석 : 야생`**으로 바뀌었습니다.

### 7-3. 시작용 (올비아·입문)

올비아 강의·물교 10회·섬 지식 구간에서는 **싸게 맞출 수 있는 경험치 조합**이면 충분합니다. **생활 통합 UI → 항해/교역**에 장착하세요.

| 목적 | 유물 2칸 | 광명석 조합 | 이유 |
| --- | --- | --- | --- |
| **항해 레벨 올리기** | 항해 경험치 + 항해 숙련도 | **미지 ×3~4** (흔들흔들 / 하늘과 바다) | 오색빛 없이 바로 가능 |
| **물물교환·교역 레벨** | 교역 경험치 + 항해 숙련도 | **수완 ×3~4** (저울 / 장학생) | 교역 경험치 집중 |
| **항해·교역 둘 다 (여유 시)** | 항해 경험치 + 교역 경험치 | 미지·수완을 섞어 가며 재료 모으기 → 최종 **바다의 포옹**으로 교체 | 입문~중반 브릿지 |

```
입문 예시
  생활 UI · 항해/교역 탭
  유물: 세스라 항해 경험치 + 항해 숙련도
  광명석: 미지 미지 미지 (또는 미지×4)
```

### 7-4. 최종 추천 (항해·교역 병행)

물물교환과 항해를 **같이** 키울 때의 정석 세팅입니다. ([2026 생활 유물·광명석 추천](https://www.inven.co.kr/board/black/3584/59027) · 공식 조합식 · [9/2 생활 통합](https://www.kr.playblackdesert.com/ko-KR/News/Detail?groupContentNo=16141&countryType=ko-KR))

| 슬롯 | 추천 |
| --- | --- |
| **장착 UI** | **생활 통합 → 항해/교역** |
| **유물 1** | **세스라의 유물 — 항해 숙련도** |
| **유물 2** | **세스라의 유물 — 항해 경험치** *(또는 교역 경험치)* |
| **광명석 ①②③④** | **미지 · 수완 · 파랑 · 오색빛** |
| **조합** | **〈바다의 포옹〉** — 항해 경험치 +10% · 교역 경험치 +10% · 항해 숙련도 +45 · 인어의 소망 III |

```
최종 세팅 (생활 UI · 항해/교역)
  유물: 항해 숙련도 + 항해 경험치 (또는 교역 경험치)
  광명석: 미지 / 수완 / 파랑 / 오색빛  →  〈바다의 포옹〉
```

| 상황별 변형 | 조합 | 언제 |
| --- | --- | --- |
| **항해 레벨만 폭파** | **너울빛 동행** (미지×3+오색) 또는 **선택과 집중 : 항해** (미지×2+야생+오색) | 숙련도 여유 충분할 때만 (−500 주의) |
| **교역 레벨만** | **교섭의 달인** (수완×3+오색) | 물교만 몰아찍을 때 |
| **숙련도만** | **위대한 물결** (파랑×3+오색) | 항해 장비·기술 해금 우선 |

> **선택과 집중 : 항해**는 숙련도 **−500**입니다. 항해복·일지·유물 합산 숙련도에 여유가 있을 때만 쓰세요.

### 7-5. 수급 팁

| 재료 | 얻는 법 |
| --- | --- |
| 세스라 유물·풀의 광명석 | 생활·돌발(달리사인)·항해/물교 활동 중 드롭 · 거래소 |
| 오색빛 광명석 | 거래소 · 합성 |
| 장착 | **생활 통합 UI → 항해/교역** (옷에 꽂지 않음 · 가문 공유) |

올비아 주화로 **마노스 항해사의 옷 / 항해 일지**를 고르면 숙련도 기반이 탄탄해져, 위 최종 세팅 체감이 좋아집니다. (의상은 숙련도·외형용 · **유물 슬롯은 생활 UI**)

## 수료 보상 (항해/교역)

공식 생활 수업 기준, 항해/교역은 채집·요리와 경험치 곡선이 다릅니다.

| 단계 | 항해/교역 레벨 |
| --- | --- |
| 강의 의뢰 완료 | **숙련 Lv.1** |
| 아카데미 패스 일반 보상 | **숙련 Lv.5** |
| 아카데미 패스 추가 보상 | **전문 Lv.1** |

추가로 생활 수업 전체 보상에 **파란색 고(III) 항해 장비**, 크론석, 주화 교환용 재화 등이 포함됩니다. 주화로는 **마노스 항해사의 옷 / 항해 일지** 등도 고를 수 있습니다. ([공식 가이드](https://www.kr.playblackdesert.com/ko-kr/Wiki?wikiNo=429))

## 자주 막히는 지점

| 증상 | 해결 |
