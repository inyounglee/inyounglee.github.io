# 크로그달로의 둥지 제작 가이드

**크로그달로의 둥지**는 **꿈결 환상마 3종**(아두아나트·디네·둠)을 **전용 마구간**에 보관·소환하는 보물입니다. 지형에 맞는 환상마를 **즉시 교체**할 수 있어 이동 편의가 큽니다.

---

## 효과 요약

| 항목 | 내용 |
| --- | --- |
| 보관 | 꿈결 3종 + **크로그달로** 등 최대 **5마리** |
| 소환 | 평지 **둠**, 수변 **디네**, 산악 **아두아나트** 등 상황별 |
| 이동 | **메이드**로 다른 캐릭터·위치로 **둥지 자체 이동** 가능 |
| 제한 | **가문당 1개** |
| 거래 | **불가** |

### 메이드 호출 거리 (둥지 소지 캐릭 기준)

| 피리 | 호출 거리 |
| --- | --- |
| **천마의 뿔피리** | 무제한 |
| **조련사의 피리** | 500 |
| 기본 | 150 |

---

## 선행 조건 — 꿈결 환상마 3종

| 환상마 | 특성 |
| --- | --- |
| **꿈결 아두아나트** | 산악 |
| **꿈결 디네** | 수변·근해 |
| **꿈결 둠** | 평지 |

### 환상마 몽상 (공통)

- 같은 종 **레벨 30+ 암수 각 1마리**
- **꿈을 부르는 향로** (그믐달 향로 + 몽상 재료)
- **돌꼬리 언덕**·**그라나** — **3%** 시작, 실패 시 **+0.2%**, **30회 확정**

## [크로그달로의 둥지] 연속 의뢰

꿈결마 **탑승 상태**로 그라나 **<최고정령> 메린돌라** 방문.

| 연속 의뢰 | 목표 |
| --- | --- |
| 크로그달로의 씨앗 | 메린돌라와 대화 |
| 첫째, 바람 | **크로그달로의 자취**에 **꿈결 아두아나트** 데려가기 |
| 둘째, 대지 | 크로그달로의 자취에 **꿈결 디네** |
| 셋째, 불꽃 | 크로그달로의 자취에 **꿈결 둠** |
| 크로그달로의 선물 | 크로그달로의 자취와 대화 → **크로그달로의 둥지** |

> 완료 시 **<천마의 인도자>** 칭호 (의뢰·걸작 의뢰 중복 확인).

## 팁

- 사냥 조합이 아니라 **환상마 3종 + 연속 퀘** — 몽상 RNG가 1차 병목.
- 둥지에 맡긴 말은 **부캐·시즌캐**에도 메이드로 넘기기 좋습니다.
- 무역품 보유 말·붉은 전장 등에서는 **소환 제한**.
