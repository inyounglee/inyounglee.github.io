# 검은사막 수렵 생활 가이드

수렵은 **화승총**으로 수렵 몬스터를 잡고, **도축용 칼**로 채집하는 생활 콘텐츠입니다. 일반 공격으로는 수렵 몬스터에게 거의 피해가 들어가지 않으므로, 장비·버프·레벨 루트를 **수렵 전용**으로 따로 잡는 것이 좋습니다.

결론부터 정리하면 추천 성장 순서는 다음과 같습니다.

```
입문 (화승총 + 도축칼)
  → 의뢰·올비아 수렵 강의로 레벨업
  → 로기아 세트 (+강화)
  → 로바우 세트 (+강화)
  → 마노스 세트 동(V) (최종)
```

---

## 1. 수렵에 꼭 필요한 장비

수렵에 실제로 영향을 주는 장비는 **4종**입니다.

| 부위 | 역할 | 없으면? |
| --- | --- | --- |
| **화승총** | 수렵 몬스터 공격 | 피해 거의 0 |
| **도축용 칼** | 사체 채집·경험치 획득 | 잡아도 경험치·전리품 없음 |
| **수렵복** | 숙련도·경험치·화승총 해금 | 효율 급감 |
| **수렵 가방** | 숙련도·경험치·무게 | 채집량·이동성 불리 |

> **탑승물**은 필수 장비는 아니지만, 칼크·대왕고래·원거리 추적 수렵에서 **말**이 있으면 장전 중 이동이 가능해 체감 난이도가 크게 내려갑니다.

### 1-1. 화승총 — 입문부터 명장까지

화승총은 **수렵 레벨**과 **수렵 숙련도** 조건을 동시에 봅니다. 숙련도가 올라가면 **레벨 조건 없이** 상위 화승총을 쓸 수 있는 경우도 있습니다.

| 화승총 | 수렵 레벨 (대략) | 숙련도 해금 |
| --- | --- | ---: |
| [수렵] 초급 화승총 | 초급 1+ | — |
| [수렵] 견습 화승총 | 초급 10+ | 100+ |
| [수렵] 숙련 화승총 | 견습 10+ | 200+ |
| [수렵] 전문 화승총 | 숙련 10+ | 300+ |
| [수렵] 장인 화승총 | 전문 10+ | 400+ |
| [수렵] 명장 화승총 | 장인 10+ | — |
| [수렵] 저격총 | — | 50+ |

**입문용 획득 방법**

| 방법 | 내용 |
| --- | --- |
| **공헌도 대여** | `[공헌도] 연습용 화승총` — 초반 체험용 (내구 무한, 반납 시 공헌도 회수) |
| **직접 제작** | 집 **도구공방** 1단계부터 단계별 제작 |
| **거래소** | 주 무기 카테고리에서 구매 |

**화승총 조작 요약**

- 우클릭: 장전 / 좌클릭: 발사
- **Q (앉기):** 사거리·장전 속도 증가 → 실전에서 거의 필수
- Shift + WASD: 회피
- 말 탑승 중 사격 가능

**강화 주의:** +7까지는 비교적 안전, **+8 이상**부터 실패 시 단계 하락. 여유 없으면 **+7 이하** 권장.

### 1-2. 도축용 칼 — 가장 많이 빠뜨리는 준비물

수렵 몬스터를 죽여도 **도축에 성공해야** 경험치와 고기·부산물을 받습니다.

- 채집 등급에 맞는 **도축용 칼** 아무거나 사용 가능
- **내구도**만 챙기면 됨 (여분 칼 또는 수리)

올비아 아카데미 **[수렵 강의] 거대 ○○ 사냥** 의뢰마다 도축이 포함되어 있으므로, 강의 시작 전에 칼을 꼭 준비하세요.

## 2. 장비 스펙업 — 단계별 로드맵

수렵복·가방은 **로기아 → 로바우 → 마노스** 순으로 교체합니다. 상위 장비일수록 기본 **숙련도·경험치%**가 높고, 강화 시 숙련도·경험치가 더 오릅니다.

> 단계별 **숙련도·경험치 수치 전체 표**는 **[수렵복 비교 가이드](https://www.inyounglee.kr/blackdesert/2026/09/01/hunting-armor-stats-comparison/)** 를 참고하세요.

### 2-1. 단계별 비교

| 단계 | 수렵복 | 수렵 가방 | 기본 숙련도 (복/가방) | 경험치 (복) | 비고 |
| --- | --- | --- | --- | --- | --- |
| 입문 | 사냥꾼의 옷 | (없음) | — | — | 숙련도 보너스 없음 |
| **1단계** | **로기아 수렵꾼의 옷** | **로기아 수렵 가방** | +3 / +3 | +3% / +10% | 고(III) +130·+23% / 동(V) +280·+28% ([비교표](https://www.inyounglee.kr/blackdesert/2026/09/01/hunting-armor-stats-comparison/)) |
| **2단계** | **로바우의 수렵복** | **로바우 수렵 가방** | +4 / +4 | +4% | 고(III) +180·+24% ([비교표](https://www.inyounglee.kr/blackdesert/2026/09/01/hunting-armor-stats-comparison/)) |
| **3단계 (최종)** | **마노스 수렵꾼의 옷** | **마노스 수렵 가방** | +5 / +5 | +5% | 동(V) +400·+40% ([비교표](https://www.inyounglee.kr/blackdesert/2026/09/01/hunting-armor-stats-comparison/)) |

### 2-1-1. 수렵복 강화 단계별 스탯 (고·유·동)

로기아·로바우·마노스 공통으로 **장(I)~동(V)** 까지 강화할 수 있습니다. 아래는 **수렵복만** 착용했을 때의 숙련도·경험치%입니다.

| 강화 | 로기아 숙련도 | 로기아 경험치 | 로바우 숙련도 | 로바우 경험치 | 마노스 숙련도 | 마노스 경험치 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| **고(III)** | +130 | +23% | +180 | +24% | +220 | +25% |
| **유(IV)** | +200 | +23% | +250 | +24% | +300 | +25% |
| **동(V)** | +280 | +28% | +330 | +33% | +400 | +40% |

> 로기아 **기본**은 숙련도 +3·경험치 +3%입니다. 로기아를 **동(V)** 까지 올려도 경험치 **+28%** 로 **마노스 고(III) +25%** 와 비슷한 수준이므로, 응축 결정 투자 전 **로바우·마노스 교체 시점**을 [비교표](https://www.inyounglee.kr/blackdesert/2026/09/01/hunting-armor-stats-comparison/)에서 함께 검토하세요.

**획득 방법:** 대장장이 **제작**, **통합 거래소** 구매, **올비아 아카데미 보상** (아래 5장).

### 2-2. 강화 재료

| 강화 구간 | 수렵복·가방 재료 |
| --- | --- |
| +1 ~ +15 | **검은 결정** (가방 +1~15는 **블랙스톤**) |
| 장(I) ~ 동(V) | **응축된 마력의 검은 결정** (가방은 **응축된 마력의 블랙스톤**) |

**특징**

- 로기아·로바우·마노스 생활 장비는 **발크스 스택(강화 확률 증가) 영향 없음** — 고정 확률
- 실패해도 **파괴 없음** (고대의 모루·아그리스 정수로 확정 강화 가능)
- 마노스 옷은 **+5까지 잠재력 돌파 실패 없음**

### 2-3. 추천 강화 목표

| 구간 | 목표 | 이유 |
| --- | --- | --- |
| 로기아 | **+15·장(I) ~ 고(III)** | 출항·올비아 전 실질 목표 (+130 / +23%) |
| 로기아 (선택) | **유(IV)~동(V)** | +280 / +28%까지 가능하나 **로바우·마노스 교체**가 보통 더 효율적 |
| 로바우 | **장(I)~고(III)** | 중반 의뢰·발타라 전 (+180 / +24%) |
| 마노스 | **동(V)** | 숙련도 +400·경험치 +40%, 저격총·명중률 |

> 크론석은 **마노스 동(V) 직전**에 쓰는 편이 낫습니다. 로기아·로바우 구간은 검은 결정·뾰족한 흑결정(뭉퉁 고래 등)으로 충분한 경우가 많습니다.

### 2-4. 숙련도가 열어 주는 것

수렵복·가방 숙련도가 쌓이면 **내 정보(P) → 생활** 탭에서 확인할 수 있습니다.

| 숙련도 | 효과 |
| ---: | --- |
| 50+ | [수렵] **저격총** 사용 |
| 100+ | [수렵] **견습** 화승총 (레벨 무관) |
| 200+ | **숙련** 화승총 |
| 300+ | **전문** 화승총 |
| 400+ | **장인** 화승총 |

추가로 숙련도가 오를수록 **채집량 증가**, **희귀 재료 확률**, **저격총 명중률**이 올라갑니다.

## 3. 필수·추천 버프

### 3-1. 거의 필수 (레벨업·숙련도)

| 종류 | 아이템 | 효과 |
| --- | --- | --- |
| **음식** | **해물을 곁들인 크론 정식** | 생활 경험치 +8%, 숙련도 상승 |
| **영약** | **신록의 영약** | 생활 경험치 (대부분 생활 공통) |
| **연금석** | **생명의 정령석** → 후반 **칸의 심장 : 생명** | 생활 숙련도 보조 |

> 생활 콘텐츠는 **해물 크론 정식 + 신록의 영약**만 챙겨도 체감이 큽니다. 거래소에서 구매하거나 요리·연금으로 직접 제작할 수 있습니다.

### 3-2. 수렵 전용·편의 버프

| 종류 | 아이템 | 효과 |
| --- | --- | --- |
| 요리 | **사냥꾼의 샐러드** | 화승총 **재장전 속도** ↑ |
| 요리 | **칼크의 담금주** | 재장전 + 공격력 + 이동속도 |
| 요리 | **햄버그** (사자 고기) | 수렵·전투 겸용 |
| 교회 | **엘리온교의 축복 — 모험** 등 | 경험치·능력치 (3M 은화 등) |
| 별채 | 생활 경험치 별채 | 거점 별채 설치 시 |
| 의상 (유료) | **그랑베어 의상** | 수렵 경험치 +15%, 장전 탄 +1 등 |
| 가구 | **머리 박제** (수렵 전리품) | 주거지 버프 (회복·공격력 등) |

**실전 팁:** 장전 중 움직일 수 없어 맞기 쉽습니다. **사냥꾼의 샐러드**는 초보보다 **중급 이후** 체감이 큽니다. 카이아 호수 **민물 악어** 고기로 제작 가능.

### 3-3. 버프 적용 순서 (출발 전)

```
1. 해물 크론 정식
2. 신록의 영약
3. (선택) 사냥꾼의 샐러드 / 칼크의 담금주
4. 연금석 장착 (생명의 정령석 or 칸의 심장 : 생명)
5. (선택) 교회 버프 · 별채 · 그랑베어 의상
```

## 4. 효율적인 레벨업 루트

### 4-1. 전체 흐름

| 순서 | 구간 | 목표 레벨 | 장비 |
| --- | --- | --- | --- |
| 0 | 올비아 **수렵 강의** (입학 중) | 초급~견습 | 공헌도 화승총 → 로기아 |
| 1 | **출항! 수렵의 길** 연속 의뢰 | **숙련 1+** | 견습~숙련 화승총 |
| 2 | 발레노스 산맥·섬 반복/일일 | 숙련~전문 | 로기아+ |
| 3 | 카마실비아 발타라 등 | 전문~장인 | 로바우+ |
| 4 | 숙련도·의뢰 병행 | 명장 | 마노스 |

### 4-2. 1순위 — 출항! 수렵의 길 (추천 의뢰)

**O → 추천 의뢰** 탭의 **「출항! 수렵의 길」** 연속 의뢰를 끝까지 진행합니다.

- **발레노스 군도 섬** 위주
- 완료 시 **숙련 Lv.1 이상** 달성 가능 (공식 가이드)
- 보상: **화승총**, **칭호**, 기타 수렵 보조 아이템
- 이후 **매일/반복 의뢰** 해금 → **수렵꾼의 증표** 파밍

**준비물:** 나룻배·어선, 잠수/낚시 의상(이동 속도), 화승총, 도축칼, 거점 **수리 NPC** 활용.

### 4-3. 2순위 — 지역별 파밍

| 지역 | 대상 | 난이도 | 비고 |
| --- | --- | --- | --- |
| **올비아·발레노스 산맥** | 거대 사슴·멧돼지·불곰 | ★ | 최초 연습 |
| **발레노스 군도** | 의뢰 연계 몬스터 | ★★ | 증표·경험치 |
| **칼페온 카이아 호수** | 민물 악어 | ★★ | 사냥꾼 샐러드 재료, 리스폰 김 |
| **칼페온 해역** | 뭉퉁 고래 | ★★ | 검은 결정·흑결정 |
| **카마실비아 발타라** | 일일/반복 의뢰 | ★★★ | **전문 1+** 필요 |
| **발렌시아 아레하** | 거대 사자·암사자 | ★★★ | 경험치 효율 좋음 |

**레벨업 원칙**

1. **의뢰 우선** — 같은 시간에 경험치 + 은화 + 증표
2. **도축 실패 zero** — 칼 내구·무게 확인
3. **버프 유지** — 크론 정식·신록은 30~120분마다 갱신
4. **화승총 등급** — 레벨 올릴 때마다 상위 총으로 교체

### 4-4. 수렵꾼의 증표

반복·일일 의뢰 보상 **수렵꾼의 증표**는 **벨리아 이고르 바탈리**에게 가져가면:

- **우두머리 토벌 의뢰서** 교환
- 기타 수렵 관련 아이템 교환

증표는 의뢰 효율의 핵심 재화이므로, 레벨업 구간에서 의뢰를 끊지 않는 것이 좋습니다.

## 5. 올비아 아카데미 — 수렵 강의·보상

올비아 아카데미 입학 중(레벨 60+)이라면 **수렵 강의**만으로도 로기아급 장비와 **장인 1**까지 밀 수 있습니다.

### 5-1. 수렵 강의 의뢰 순서

**NPC 레오**에게서 `[수렵 강의]` 연쇄 의뢰를 진행합니다.

| 의뢰 | 내용 |
| --- | --- |
| 수강 신청 | 레오에게 대화 |
| 수렵의 기본, 화승총 | 재료 상인 NPC에서 화승총 수령·장착 |
| 거대 큰 뿔 사슴 | 사슴 5 + 사슴 고기 10 |
| 거대 멧돼지 | 멧돼지 5 + 돼지고기 10 |
| 거대 불곰 | 불곰 1 + 곰고기 5 |
| 카마실비아 수렵 | 깃털늑대·페리 각 10 + 고기 |
| 끝없는 겨울산 수렵 | 서리늑대 10 |
| 오딜리타 수렵 | 녹음록·녹음사슴·풀코뿔소 |
| 증명, 야생의 불꽃 | **야생의 불꽃 200** (부산물) |
| 수료식 | 채팅 「올비움, 프론티아!」 |

> 올비아 강의는 **카마실비아·겨울산·오딜리타**까지 다루므로, 출항 의뢰보다 **한 번에 넓은 지역**을 경험할 수 있습니다. **야생의 불꽃 200**은 오딜리타 수렵이 가장 수월합니다.

### 5-2. 수렵 강의 — 아카데미 패스 보상

| 달성 | 수렵 레벨 |
| --- | --- |
| 수렵 강의 완료 | **장인 Lv.1** |
| 패스 일반 보상 전부 | **장인 Lv.5** |
| 패스 추가 보상 (100은화) | **명장 Lv.1** |

패스는 **매 의뢰마다 수렵 경험치**가 쌓이므로, premium 패스(기수 한정 100은화)는 수렵만 파고들 계획이면 가성비가 좋습니다.

### 5-3. 수렵 가문 보상 (수렵 강의 완료 시)

올비아 UI → **가문 보상 — 생활** 에서 수렵 분야 보상을 받습니다. (생활 **전 분야** 수료 시 일괄 구조이며, 수렵 강의 완료가 진행도에 반영됩니다.)

**수렵 분야 대표 보상**

| 아이템 | 등급·용도 |
| --- | --- |
| **로바우 수렵꾼의 옷** (TRI / **고 III**) | 로기아 다음 단계 — **즉시 착용** |
| **로바우 수렵 가방** (TRI / **고 III**) | 로기아 가방 교체 |
| **응축된 마력의 검은 결정** ×20 | 로바우·마노스 **장(I)~** 강화 |
| **응축된 마력의 블랙스톤** ×20 | 가방 강화 |
| **크론석** ×1,000 | 마노스 상위 강화 예약 |

> 영문 가이드 기준 **TRI Robeau** = 한국 **고(III) 로바우** 계열. 올비아만으로 **로기아를 건너뛰고 로바우**까지 받을 수 있어, 수렵 입문에 가장 큰 지원입니다.

### 5-4. 올비아 주화 — 수렵 관련 교환

졸업 전 **아카데미 주화**로 추가 장비를 노릴 수 있습니다.

| 교환품 | 주화 | 수렵 활용 |
| --- | ---: | --- |
| **[아카데미] 모험가의 생활 준비 선택 상자** | 60 | **고(III) 마노스 수렵꾼의 옷** or **마노스 수렵 가방** 선택 |
| **검은 결정** ×100 | 10 | +1~+15 강화 |
| **크론석** | 1 | 마노스 강화 |

**모험가의 생활 준비 상자** (가문당 1회)에서 **마노스 수렵복/가방**을 고르면, 로바우 → **마노스 직행** 루트가 됩니다. 복·가방 **한쪽만** 부족할 때 선택하세요.

### 5-5. 올비아 수렵 vs 일반 루트

| | 올비아 수렵 강의 | 일반 출항 의뢰 |
| --- | --- | --- |
| 장비 | **로바우 고III** + (주화) **마노스** | 직접 제작·구매 |
| 레벨 | **장인~명장** (패스) | **숙련~전문** |
| 시간 | 강의 일괄 (1~2일) | 분산 파밍 |
| 조건 | **60+ · 아카데미 입학** | 없음 |

이미 올비아를 **전투만** 수료했다면, 수렵 강의·생활 보상은 **같은 기수** 안에서 병행해야 합니다. [하이퍼 부스트·올비아 장비 가이드](https://www.inyounglee.kr/blackdesert/2026/08/15/hyper-boost-equipment-guide/)와 함께 보면 일정 잡기 쉽습니다.

## 6. 최종 세트까지 — 실전 스펙업 순서

```
[입문]
  공헌도 연습용 화승총 + 도축칼
  ↓
[레벨]
  출항! 수렵의 길 OR 올비아 수렵 강의
  ↓
[1차 장비] 로기아 복·가방 (+15·장 ~ 고, 선택 시 동)
  ↓  (올비아면 로바우 보상으로 스킵 가능)
[2차 장비] 로바우 복·가방 (장~고)
  ↓
[3차 장비] 마노스 복·가방 → 동(V)
  ↓
[숙련도] 해물 크론 + 신록 + 칸의 심장 : 생명
  ↓
[콘텐츠] 대왕고래 · 칼크 · 라우라우 (협동)
```

| 시점 | 착용 목표 | 수렵 레벨 |
| --- | --- | --- |
| 1주차 | 로기아 고(III)~ + 견습~숙련 총 | 견습~숙련 |
| 올비아 완료 | **로바우 고III** (+ 주화 마노스) | **장인** |
| 중기 | 로바우 강화 + 전문~장인 총 | 전문~장인 |
| 최종 | **마노스 동(V)** + 명장 총 | **명장** |

## 7. 자주 하는 실수

| 실수 | 해결 |
| --- | --- |
| 도축칼 없이 수렵 | **도축용 칼** 필수 |
| 일반 무기로 공격 | **화승총**만 유효 |
| 버프 없이 파밍 | **해물 크론 + 신록** |
| 로기아에 크론 낭비 | **마노스**까지 아껴 두기 |
| 올비아 로바우 안 받음 | UI **가문 보상 — 생활** 확인 |
| 앉기(Q) 미사용 | 사거리·장전 속도 ↑ |

## 8. 체크리스트

### 장비

```
□ 화승총 (레벨·숙련도에 맞는 등급)
□ 도축용 칼 (+ 여분)
□ 수렵복 (로기아 → 로바우 → 마노스)
□ 수렵 가방
□ (후반) 말 — 칼크·추적용
```

### 버프

```
□ 해물을 곁들인 크론 정식
□ 신록의 영약
□ (선택) 사냥꾼의 샐러드
□ (후반) 칸의 심장 : 생명
```

### 레벨업

```
□ (선택) 올비아 수렵 강의 + 패스
□ 출항! 수렵의 길 완료
□ 발레노스 반복/일일 의뢰
□ 증표 → 이고르 바탈리 교환
□ 발타라·아레하 등 상위 지역
```

### 올비아 (해당 시)

```
□ [수렵 강의] 전체 수료
□ 가문 보상 — 로바우 복·가방
□ 패스 — 명장 1
□ 주화 — 마노스 선택 상자 (필요 시)
```

## 정리

수렵은 **화승총 + 도축칼 + 수렵복/가방** 세트가 갖춰져야 시작이고, **해물 크론 정식·신록의 영약**이 레벨 속도를 결정합니다. 장비는 **로기아 → 로바우 → 마노스 동(V)** 이 정석이며, **올비아 아카데미 수렵 강의**는 로바우 고III와 장인~명장 레벨을 한 번에 밀어 주는 가장 큰 지원입니다. 수렵복 단계별 숙련도·경험치는 **[비교표](https://www.inyounglee.kr/blackdesert/2026/09/01/hunting-armor-stats-comparison/)** 에서 확인할 수 있습니다.

※ 패치에 따라 장비 등급·올비아 일정·가문 통합 생활 장비 등이 변경될 수 있습니다. 진행 직전 [검은사막 공식 홈페이지](https://www.kr.playblackdesert.com/) 공지를 확인하세요.
