# 검은사막 요정작 가이드

요정 레이라는 사냥 중 **회복제를 대신 먹고**, 찬란 등급이면 **음식·영약·주문서도 대신 씁니다.** 손으로 물약을 누르지 않아도 딜이 끊기지 않습니다.

```
입문     흑정령 의뢰 → 요정 획득
저렴     신비한 응원만 있으면 됨 (등급 무관)
최종     찬란 50레벨 + 응원 V(2초) + 아낌없는 손길 V(25종)
```

물약은 [오네트의 정령수](/blackdesert/2026/09/02/treasure-onet-elixir-guide/)(생명력)와 [오도어의 정령수](/blackdesert/2026/09/02/treasure-odore-elixir-guide/)(정신력·투지·신성력)가 있으면 무게 0·무한입니다. 없어도 일반 회복제를 응원에 등록하면 됩니다.

---

## 빠르고 저렴하게 {#cheap}

### 요정 얻기

53레벨 이상이고 아래 **하나**를 끝낸 뒤, 흑정령 추천 의뢰 **`[모험 지원] 요정, 신비스러운 동행`** 을 진행합니다. 보상이 **봉인된 요정의 날개**입니다.

- 구 칼페온 메인 (`[우두머리] 공포의 마녀` 또는 모험가 소집)
- 끝없는 겨울의 산 (`[겨울산] 아르옐리의 문 너머`)
- 조르다인 사가 (`[칼페온] 후일담 III`)
- 아침의 나라 (`[아침의 나라] 한걸음 더`)
- 특별 성장 푸가르의 비망록 5장 (간소화 메인)

추가 날개는 **레이라의 꽃잎 2개**를 카마실브 사원 **테이아**에게 주면 교환됩니다. 꽃잎은 사냥·채집·낚시, 또는 불안정한 균열에 **특상품 꿀단지**.

### 사냥에 필요한 기술 하나

**신비한 응원**만 있으면 최소선입니다. 생명력·자원이 일정 % 아래로 떨어지거나 상시로, 등록한 회복제를 자동 사용합니다.

| 단계 | 재사용 | 배울 수 있는 등급 |
| --- | --- | --- |
| I | **6초** | 희미한~찬란 |
| II | 5초 | 선명한~찬란 |
| III | 4초 | 선명한~찬란 |
| IV | 3초 | 영롱한~찬란 |
| **V** | **2초** | **찬란만** |

기술 단계는 **획득 후 올리거나 내릴 수 없습니다.** 낮은 등급에서 응원 I만 나와도 사냥은 됩니다. 2초(V)는 찬란 + 운(또는 테이아 구슬)입니다.

요정 창에서 응원을 켜고, 생명력·정신력 회복제를 등록하세요. [사냥 준비](/blackdesert/2026/09/22/hunting-prep-guide/)의 도핑 음식·영약은 손길이 없으면 직접 먹습니다.

성장 재료(달콤한 벌꿀주, 오네테아 흑벌꿀주, 녹색 장비)로 레벨만 올려도 기술 칸이 늘어납니다. 등급별 최대 레벨:

| 등급 | 최대 레벨 |
| --- | --- |
| 희미한 | 10 |
| 선명한 | 20 |
| 영롱한 | 30 |
| 찬란한 | 50 |

이 단계 비용은 **의뢰면 0**. 벌꿀주·꽃잎을 사면 수천만~억 단위입니다.

---

## 최종 단계 — 찬란 + 응원 V + 손길 V {#final}

최종은 **찬란한 날개, 50레벨**, 핵심 기술 두 개입니다.

1. **신비한 응원 V** — 회복 주기 2초. 오네트 무한 물약과 주기가 맞습니다.
2. **아낌없는 손길 V** — **찬란만**. 버프가 끝나면 지정 아이템을 다시 씁니다.

### 아낌없는 손길

| 단계 | 자동 사용 개수 |
| --- | ---: |
| I | 5 |
| II | 8 |
| III | 12 |
| IV | 16 |
| **V** | **25** |

크론 정식·음식, 영약·비약, 향수, 주문서를 넣을 수 있습니다. 프리셋 1~3이 있어서 은화 사냥 / 경험치 사냥을 나눠 두는 것이 편합니다. UI 좌클릭이 설정, 우클릭이 ON/OFF입니다.

손길에 넣으면 좋은 최소 목록은 [사냥 준비 — 도핑](/blackdesert/2026/09/22/hunting-prep-guide/#doping)과 같습니다. 상줌 2, 크론 정식, 야수(또는 조화)의 영약부터입니다.

그 외 있으면 좋은 기술:

| 기술 | 사냥에서의 의미 |
| --- | --- |
| 깃털같은 발걸음 | 무게 초과 둔화 완화 (V는 125%까지) |
| 요정의 눈물 | 경험치 안 깎고 즉시 부활 (V는 1시간) |
| 마르지 않는 우물 | 사막 질병 약 자동 (발렌시아) |
| 샛별 | 주변 조명. 전투력과 무관 |

### 날개돋이

최대 레벨이 되면 **날개돋이**로 다음 등급을 노립니다. 희미한 → 선명한 → 영롱한 → 찬란. 찬란이 끝입니다.

| 현재 등급 | 달콤한 벌꿀주 1개 | 오네테아 흑벌꿀주 1개 |
| --- | ---: | ---: |
| 희미한 | 2% | 33% |
| 선명한 | 1% | 10% |
| 영롱한 | 1% | 4% |

- 날개돋이 **성공 시 기술은 전부 초기화**됩니다.
- **실패하면 그 요정으로는 재도전할 수 없고**, 환생이 필요합니다.
- 실사용은 **오네테아 흑벌꿀주** 쪽이 맞습니다. 영롱→찬란 4%라 기댓값이 큽니다. 벌꿀주 시세·개수는 운에 따라 **수억**이 흔합니다.

### 환생·기술 변경

- **요정여왕의 권능**으로 성장 환생(기술 초기화) 또는 성격 환생.
- **테이아의 구슬**로 원치 않는 기술만 변경. 필요 개수 = 현재 기술 개수. 변경 전 확률을 미리 볼 수 있습니다. 구슬은 펄 상점(개당 흔히 **50펄**) 또는 이벤트.

최종 비용은 날개돋이 운 + 구슬 소모라 **은화/펄 모두 편차가 큽니다.** 응원만 있는 요정으로 먼저 돌고, 은화가 안정되면 찬란을 노리는 순서가 [사냥 준비](/blackdesert/2026/09/22/hunting-prep-guide/)와 맞습니다.
